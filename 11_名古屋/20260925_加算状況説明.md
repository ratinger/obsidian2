# 厚労省「介護報酬の加算状況」の読み方

対象: 介護付き有料（特定施設入居者生活介護）。[介護サービス情報公表システム](https://www.kaigokensaku.mhlw.go.jp/23/index.php?action_kouhyou_pref_topjigyosyo_index=true) の事業所ページにある「介護報酬の加算状況を見る」。

調べた日: 2026-09-25。単位は令和6年4月改定（特定施設）。自己負担はだいたい「単位×10円×負担割合」。1割なら単位がそのまま円の目安。

見方

- **あり**: 記入日前月から直近1年で、その加算を請求した
- **なし**: その1年は請求していない。できない、しなかった、該当者がいなかった、のどれか。見学で聞く
- **予防を除く**: 要支援の介護予防特定施設では取れない。要介護の人向け
- 加算は介護保険の上乗せ。月額の家賃・管理費・食費とは別。ホームの体制の手がかりになる

| 項目 | 何の加算か | 家族として見ると | 単位の目安 |
| --- | --- | --- | --- |
| 入居継続支援加算（Ⅰ） | たん吸引・胃ろうなどが必要な人が一定以上いて、介護福祉士も厚い | 医療的ケアが重い人をホーム内で看ている。Ⅰの方が条件が厳しい | 1日36 |
| 入居継続支援加算（Ⅱ） | 上と同じ方向だが、医療的ケアが必要な人の割合がⅠより低い | 医療ケアはあるがⅠほど多くない | 1日22 |
| 生活機能向上連携加算（Ⅰ） | 外部のリハ職と一緒に体の評価と計画を作る。3か月に1回まで | 外部の専門職の目が入る。頻度は低い | 月100（3月に1回まで） |
| 生活機能向上連携加算（Ⅱ） | 外部リハ職と連携して、毎月機能訓練する | Ⅰより継続的。個別機能訓練と同時だと半額 | 月200（個別訓練ありなら100） |
| 個別機能訓練加算（Ⅰ） | 機能訓練指導員が、人ごとに訓練計画を立てて毎日実施 | リハビリ・体操が個別になっている | 1日12 |
| 個別機能訓練加算（Ⅱ） | Ⅰに加え、訓練の結果を国の科学的介護システム（LIFE）に送る | 記録と見直しまでしている | 月20 |
| ADL維持等加算（Ⅰ） | 入居者全体の日常動作（歩く・食べる等）の維持・改善が一定以上 | 体の機能が落ちにくい実績がある | 月30 |
| ADL維持等加算（Ⅱ） | 上と同じで、改善の度合いがより高い | Ⅰより成績がよい | 月60 |
| 夜間看護体制加算（Ⅰ） | 常勤看護師に加え、夜も看護職員が夜勤か宿直でいる | 夜の急変に看護師が建物にいる。夜間看護では一番厚い | 1日18 |
| 夜間看護体制加算（Ⅱ） | 夜は電話で看護師につながる体制（オンコール） | 夜は介護職員中心。看護師は呼べる | 1日9 |
| 若年性認知症入居者受入加算 | 65歳未満で認知症の人を受け入れ、担当者を決めて支援する | 若年性認知症の受け入れ実績 | 1日120 |
| 協力医療機関連携加算（常時相談・診療） | 協力病院がいつでも相談・診療でき、急な入院も受けられる | かかりつけ病院との関係が強い。夜間・急変向き | 月100 |
| 協力医療機関連携加算（上記以外） | 協力病院はあるが、常時の診療・入院までは満たさない | 連携はあるが一段弱い | 月40 |
| 口腔・栄養スクリーニング加算 | 半年に1回、口の中と栄養状態を確認する | 誤嚥・低栄養の点検をしている | 1回20（6月に1回まで） |
| 科学的介護推進体制加算 | 心身の状態をLIFEに送り、計画に使う | 国の様式で記録している。体制の有無の目安 | 月40 |
| 退院・退所時連携加算 | 病院や老健から入ってきた直後、情報をつないでケアする | 退院直後の受け入れが整っている | 1日30（入居後30日まで） |
| 退居時情報提供加算 | 病院などに移るとき、薬・ケアの情報を渡す | 入院・転居時の引き継ぎ | 1回250 |
| 看取り介護加算（Ⅰ） | ホームで看取る計画を立て、亡くなる前の一定期間ケアした | 施設内看取りをした実績。夜はオンコールでも可 | 死亡45〜31日前72／30〜4日前144／前々日・前日680／当日1280（1日） |
| 看取り介護加算（Ⅱ） | Ⅰに加え、看取り期に看護職員が夜勤か宿直でいる | 看取りの夜も看護師がいる。Ⅰより厚い | 同期間で572／644／1180／1780 |
| 認知症専門ケア加算（Ⅰ） | 認知症の人が多く、認知症介護実践リーダー研修などを修了した職員がいる | 認知症ケアの研修体制がある | 1日3 |
| 認知症専門ケア加算（Ⅱ） | Ⅰに加え、指導的な研修修了者がいて、研修もしている | 認知症ではⅠより厚い | 1日4 |
| 高齢者施設等感染対策向上加算（Ⅰ） | 感染対策の医療機関と連携し、研修や訓練をしている | 感染症のときの相談先がある | 月10 |
| 高齢者施設等感染対策向上加算（Ⅱ） | 感染対策の実地指導を受けた | Ⅰより軽い点検 | 月5 |
| 生産性向上推進体制加算（Ⅰ） | 見守り機器やICTを使い、委員会で負担軽減と質を確認している（上位） | 機器を使った見守り・記録の体制が厚い | 月100 |
| 生産性向上推進体制加算（Ⅱ） | 上と同じ方向の導入段階 | 機器導入はしているがⅠほどではない | 月10 |
| サービス提供体制強化加算（Ⅰ） | 介護福祉士の割合などが一番高い | 有資格者が厚い | 1日22 |
| サービス提供体制強化加算（Ⅱ） | 介護福祉士の割合がⅠの次 | 資格の厚さは中くらい | 1日18 |
| サービス提供体制強化加算（Ⅲ） | 勤続年数などの条件 | Ⅰ・Ⅱより弱い | 1日6 |
| 介護職員等処遇改善加算（Ⅰ） | 職員の給料を上げるための加算。Ⅰが最も高い率 | 職員の処遇。ケアの中身というより人件費。ほとんどのホームがどれかを取る | 所定単位の約13〜16%（区分による） |
| 介護職員等処遇改善加算（Ⅱ） | 上と同じで率がⅠの次 | 同上 | 同上 |
| 介護職員等処遇改善加算（Ⅲ） | 上と同じで率がⅡの次 | 同上 | 同上 |
| 介護職員等処遇改善加算（Ⅳ） | 上と同じで率が一番低い | 同上 | 同上 |

施設選びで先に見る項目

- 夜: 夜間看護体制（ⅠかⅡか）
- 看取り: 看取り介護（ⅠかⅡか）。なしでも看取るホームはある。重要事項と見学で確認
- 病院: 協力医療機関連携（常時相談・診療の方か）
- 医療ケア: 入居継続支援（たん吸引・胃ろうなど）
- 体を動かす: 個別機能訓練、ADL維持等
- 資格: サービス提供体制強化（Ⅰが厚い）

処遇改善は職員の給料用なので、ホーム同士の生活の差は小さい。
