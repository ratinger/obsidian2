## 1. 必要性

任意後見は、判断できるうちに「誰に・何を任せるか」を公正証書で決めておく契約。判断が落ちてから家裁が監督人を付けた時点で、初めて代理が始まる。

### 1.1 いま起きていること

和子さんは一人暮らし。体は動くが、判断と手順が止まりやすい。

- 「ボケた、助けてほしい」。クーラーの扱いが分からなくなり、切ってしまう
- 電話の前に立ち尽くす。次に何をするかが止まる
- 郵便貯金の支払いは、美奈子さんが通帳から月末に菊園へ振込している。法律上の代理ではない
- 火災保険は契約者が伸一郎、所有者は和子さん。保険金は原則和子さん名義
- 施設入居と、必要なら密柑山の売却がこれから来る。どちらも本人の署名か、正式な代理が要る

いま動けているのは、銀行・施設・保険が「家族だから」と黙認している範囲。診断名が付く、大きな契約になる、本人が拒否する、のいずれかで止まる。

### 1.2 任意後見がないと止まること


| 場面 | 任意後見がないとき | 任意後見があるとき（発効後） |
| --- | --- | --- |
| 郵便貯金の払戻し・振込 | 本人来店か、銀行が認める代理人まで。診断後は凍結しやすい | 契約に書いた口座を、後見人が払戻・振込できる |
| 施設の入居契約 | 本人署名。家族が代筆しても、ホームや保証会社が拒むことがある | 身上監護の代理権があれば、後見人が入居契約できる |
| 密柑山の売却・空き家の保険切替 | 所有者本人の意思。判断が落ちると売れない | 代理権に「処分」を入れておけば、後見人が売れる（監督人の目が入る） |
| 火災・地震の保険金 | 被保険者は和子さん。請求の署名が取れないことがある | 保険契約の代理権があれば、後見人が請求できる |
| 介護・医療の契約 | 家族が現場では進めるが、法的な代理人ではない | 入院・介護・福祉の契約は代理できる。**治療の同意そのものは後見ではできない** |

法定後見（家裁が後見人を付ける）でも上は動く。違いは、**誰が後見人になるかを自分で選べるか**。法定後見は家裁が決める。親族希望でも、弁護士・司法書士が付くことが多い。任意後見なら、美奈子さんか伸一郎かを契約で指定できる。

### 1.3 今すぐ必要か

契約そのものは、判断が残っている今しかできない。手続きは急ぐ。ただし契約した日に通帳は動かない。

- **契約（今）**: 公正証書と登記。代理はまだ不可
- **待機**: 年単位もありうる。今の菊園払い・施設見学は、これまでどおり家族実務
- **発効（判断が落ちてから）**: 名古屋家裁へ監督人の選任申立て。審判までおおむね1〜2か月

施設契約や口座を「今月動かす」手段ではない。凍結対策の土台。今の支払を正規化したいなら、任意後見と同時に**財産管理の委任契約（移行型）**を足す。任意後見だけでは、発効まで空白が残る。

### 1.4 通るかが関門

公証人が、和子さん本人の理解をその場で確認する。認知症の診断があっても、契約内容が分かれば作れる。分からなければ作れない。作れなければ法定後見（補助・保佐・後見）になる。

和子さんはすでに判断が揺れている。公証役場へ連れていく前に、契約の意味（誰に頼むか、家と口座を任せること）を短い言葉で何度か話し、反応を見る。通らなければ、その時点で家裁の法定後見を考える。遅らせると、任意後見の窓が閉じる。

### 1.5 受任者を誰にするか

法律上、子はなれる。欠格（破産、本人との訴訟など）がなければよい。


| 案 | 向く点 | 向かない点 |
| --- | --- | --- |
| 美奈子さん1人 | 近く、通帳と現場をすでに見ている。身上（施設・通院の手配）が速い | 負担が寄る。海老名から監督しにくい |
| 伸一郎1人 | 遠隔の契約・保険・費用の設計は今も伸一郎 | 名古屋の窓口に毎回行けない。銀行・施設は現地が要る |
| 2人（共同） | 片方倒れても続く | 手数料が契約の数だけ増える。銀行が「2人そろって」を求めることがある。意見が割れると止まる |
| 2人（代理権を分ける） | 財産は伸一郎、身上は美奈子、など | 文案が複雑。公証人との打ち合わせが長い |

身内なら報酬はゼロでもよい。監督人（家裁が付ける第三者。弁護士・司法書士が多い）の報酬はゼロにできない。本人の財産から月1〜3万円程度が多い。毎月が重いなら、財産側は家族信託（3章・4章）。施設契約などの身上は信託ではできない。

## 2. 具体的手続き

手続きは2段。Aが契約、Cが発効。Bは待つだけ。

| 段階 | いつ | 目安 |
| --- | --- | --- |
| **A. 契約** | 判断できるうち | 予約と文案込みで2週間〜2か月。当日の署名は30〜60分 |
| **B. 待機** | 契約後〜判断低下まで | 代理できない。見直しと「誰が申し立てるか」だけ決めておく |
| **C. 発効** | 判断が不安になってから | 資料2〜4週間 ＋ 名古屋家裁1〜2か月。鑑定が入るとさらに1〜2か月 |

### 2.1 決めてから役場へ

公証役場の前に、家族で次を一文にする。

1. **受任者**（上表）
2. **型**
   - 将来型: 任意後見だけ。今は代理しない
   - 移行型: 任意後見 ＋ 今すぐ使う財産管理の委任。判断があるうちは委任、落ちたら任意後見へ切替。公証役場の実費が増える
3. **代理権の範囲**（入れる／入れない）

和子さん向けの目安。標準目録から削っても、足してもよい。

| 入れる | 理由 |
| --- | --- |
| 預貯金・郵便貯金の払戻しと振込 | 菊園・施設費・生活費 |
| 施設の入退所契約、介護・福祉の契約 | 見学の先にある入居 |
| 保険契約の変更・請求 | 火災保険の被保険者が和子さん |
| 不動産の保存・管理 | 空き家・修繕・保険の告知 |
| 不動産の処分（売却） | 高額ホームのために家を売る合意がある。入れないと売れない |
| 登記・税務・証明書 | 売却と保険で必ず出る |
| 重要書類・通帳・印鑑の保管 | 実務の前提 |

| 入れ方を慎重に | 理由 |
| --- | --- |
| 「居住用不動産の処分は監督人の同意を要する」 | 密柑山を売る権限は残しつつ、独断を防ぐ。よく使う制限 |
| 医療の同意 | 法律上、後見人には治療同意権がない。契約に書いても効かない |

報酬は「無報酬」と書いてよい。監督人報酬は家裁が後から決めるので、契約には書けない。

### 2.2 書類（発行後3か月以内）

和子さん（委任者）

- 印鑑登録証明書 ＋ 実印（またはマイナンバーカード等の顔写真付き身分証 ＋ 認印）
- 戸籍謄本（全部事項証明書）
- 住民票

受任者（美奈子さん／伸一郎）

- 印鑑登録証明書 ＋ 実印（または顔写真付き身分証 ＋ 認印）
- 住民票

和子さんの分は [瑞穂区役所 市民課](https://www.city.nagoya.jp/mizuho/kurashi/1036662/1021760.html)（瑞穂通3丁目32番地、市民課1番申請・3番受取、平日8:45–17:15、052-852-9315〜9318）。住民票・印鑑証明は1通300円。印鑑証明は印鑑登録証が要る。

先に確認すること: **実印が登録されたままか、印鑑登録証と実印が家のどこにあるか。** 無く、本人が窓口で登録し直せるなら、契約前に再登録する。本人が理解できなければ再登録も難しい。

伸一郎は海老名市、美奈子さんは東郷町で、各自の住民票・印鑑証明を取る。

### 2.5 発効（判断が落ちてから）

申立先は**本人の住所地の家庭裁判所**。密柑山の住民票のままだと [名古屋家庭裁判所](https://www.courts.go.jp/nagoya-f/)（中区三の丸1-7-1）。窓口は1階・後見センター、052-223-2015。施設に入って住所が変われば、その住所の家裁。

申立人: 本人、配偶者、4親等内の親族、任意後見受任者。本人以外が申し立てるときは本人の同意が要る。意思表示できないときは不要。

主な添付（[裁判所の一覧](https://www.courts.go.jp/saiban/syurui/syurui_kazi/kazi_06_04/index.html)）

- 申立書（後見ポータルの書式）
- 和子さんの戸籍謄本・住民票
- 任意後見契約公正証書の写し
- 後見登記事項証明書（法務局本局。名古屋なら名古屋法務局本局）
- 家裁様式の診断書（3か月以内）。かわな病院の本間さんに、家裁の用紙を先に渡す
- 本人情報シート（谷津さんなど福祉関係者）
- 財産資料（密柑山の登記、郵便貯金の通帳写しなど）

費用の目安: 印紙800円 ＋ 登記印紙1,400円 ＋ 郵便切手（家裁指定） ＋ 診断書数千〜数万円。鑑定が付くと数万〜10万円超。監督人報酬は審判後、家裁が月額を決める。

監督人は親族ではなく専門家が多い。受任者の近い親族は監督人になれない。伸一郎が後見人なら、美奈子さんは監督人になれない、と考えておく。

名古屋家裁の法定後見は、書類がそろってから受理面接の予約が要る。任意後見監督人も、提出前に後見センターへ電話して切手額と面接の要否を確認する。

### 2.6 契約後にやること

- 正本は受任者、謄本は本人。登記完了の連絡が来たら保管場所を美奈子さん・伸一郎で共有
- 発効の申立てをする人を決めておく（受任者本人が申し立てれば足りる）
- 銀行には、契約時点では届けなくてよい（まだ代理できない）。移行型で今から払戻すなら、委任契約の正本を郵便貯金・銀行に見せ、所定の代理人届をする
- 法定後見が先に始まると、任意後見は終了することがある。契約後に家裁へ法定後見を出さない

### 2.7 次の一手（このノートの作業）

1. 美奈子さんと、財産は家族信託か任意後見か（または併用か）を決める。監督人の月額が重いなら財産は信託（3章）
2. 任意後見にするなら、受任者を1人にするか2人にするか。将来型か移行型か
3. 密柑山の売却を、信託の権限に入れるか／任意後見の代理権に入れるか
4. 実印・印鑑登録証の所在を、帰省時に確認する
5. 公証役場へ行く前に、和子さんが契約の意味を言えるかを見る（通らなければ法定後見）
6. 通らなければ、名古屋家裁の法定後見（補助から）を谷津さんとかわなに相談する

## 3. 家族信託と任意後見の比較

監督人の月額は、任意後見が始まってから死亡（または解除）まで続く。月1.5万円なら5年で90万円、10年で180万円。家族信託に家裁の監督人はいない。代わりに、最初に専門家と登記でまとまった金が要る。身上（施設契約）は信託ではできない。

### 3.1 何が違うか


| | 任意後見 | 家族信託 |
| --- | --- | --- |
| 仕組み | 代理。名義は本人のまま | 信託。不動産の登記名義は受託者。金銭は信託口口座 |
| いつ使えるか | 家裁が監督人を付けてから | 契約・登記・口座開設が終わった時点から |
| 家裁 | 発効後は監督人が毎月見る | 出ない（信託監督人は任意。親族でも可） |
| 毎月の第三者報酬 | 監督人 月1〜3万円程度。ゼロにしにくい | なし。受託者（子）は無報酬でよい |
| 初期費用 | 役場実費2〜3万円。専門家なら+10〜20万円 | 専門家30〜80万円＋役場＋信託登記。合計50〜100万円前後が多い |
| 財産の管理・売却 | 発効後はできる。居住用の売却は監督人の目が入る | 契約に書けば、受託者が売れる。家裁の許可は不要 |
| 施設の入居契約、介護の契約 | できる（身上監護） | **できない** |
| 医療の同意 | できない | できない |
| 郵便貯金のまま使う | 発効後は代理で払戻ししやすい | **ゆうちょは信託口口座を作れない。** 他行へ移す |
| 贈与税 | 代理なので移転なし | 和子さんが受益者（自益信託）なら、設定時は原則かからない |
| 相続税の節税 | ならない | ならない。死ねば信託財産も相続の対象 |
| 失敗したときの作り直し | 判断が落ちたあとでは任意後見は新規に結べない | 同じ。判断が落ちたあとでは信託も結び直せない |

和子さんで効く差は3つ。

1. **密柑山を売ること** … 信託の方が速い。受託者が契約どおり売れる。任意後見は発効待ち＋監督人
2. **施設に入ること** … 任意後見の方が厚い。信託だけでは入居契約の代理人になれない。実務では子が身元保証人になり、ホームが本人署名＋家族で通すことも多い
3. **毎月の金** … 任意後見は発効後に監督人が続く。信託は最初に高く、そのあとは帳簿と口座の手間だけ

### 3.2 費用の見え方（和子さん）

任意後見（親族が後見人・無報酬）

- 今: 2〜3万円（専門家を付けるなら+10〜20万円）
- 発効時: 印紙・切手・診断書で数千〜数万円。鑑定が付けばさらに
- その後: 監督人 月1〜3万円 × 残りの年数

家族信託（密柑山＋生活費の金銭）

- 今: 組成30〜80万円 ＋ 公正証書3〜10万円 ＋ 信託登記（登録免許税＋司法書士）
- 登録免許税は固定資産評価額。建物は0.4%。土地は令和11年3月31日まで0.3%（[国税庁](https://www.nta.go.jp/publication/pamph/sonota/0020003-124_01.pdf)）。建物評価は約405万円なので、建物分だけなら約1.6万円。土地は課税明細書の評価額で計算する（路線価約5,778万円は登録免許税の基準ではない。[[20260829_相続税の計算]]）
- その後: 監督人なし。受託者が通帳と簡単な帳簿を付ける。報酬をゼロにできる

発効が近く、そのあと数年生きるなら、任意後見の月額の方が合計で高くなりやすい。逆に、任意後見を契約だけして発効させなければ月額はゼロのままだが、その間は代理もできない。

### 3.3 この家での分け方

| 案 | 向くとき | 監督人の月額 | 施設契約 |
| --- | --- | --- | --- |
| **A. 家族信託だけ** | 止めたいのは口座凍結と家の売却。施設は身元保証で回す | なし | ホームが家族で通してくれる前提 |
| **B. 任意後見だけ** | 身上も法的に代理したい。初期を抑えたい | 発効後あり | 後見人が契約できる |
| **C. 信託＋任意後見** | 財産は信託、身上は後見 | 任意後見を発効させた時点からあり | 両方そろう |
| **D. 信託＋任意後見は契約だけ（発効しない）** | 身上はまだ家族実務。いざとなれば申し立てる | 申立てするまでなし | 発効までは家族次第 |

監督人の月額を避けたいなら、財産は **A か D**。施設の署名でホームが拒むなら B か C に戻す。先に見学先へ「後見なし・家族の身元保証で入居契約できるか」を聞く。

受託者と任意後見人を同じ人にしてもよい。分けるなら、財産の受託者は通帳を動かす人（いま払っている美奈子さん）、任意後見は身上が近い美奈子さん、もう一方を後継受託者／信託監督人にする、が分かりやすい。伸一郎を受託者にすると、登記と口座は海老名側になる。売却の意思決定には向くが、菊園の月次払いには遠い。

## 4. 家族信託のしかた

法律上の名は民事信託。家族が受託者になるものを家族信託と呼ぶ。根拠は [信託法](https://laws.e-gov.go.jp/law/418AC0000000108)。任意後見と違い、公正証書は必須ではない。ただし信託口口座も不動産の対抗も、実務は公正証書前提。

和子さん向けの型: **委託者＝受益者＝和子さん、受託者＝子の一人、後継受託者＝もう一人。** 利益は和子さんのままなので、設定時の贈与税は原則かからない。

### 4.1 決めてから専門家・役場へ

1. **目的**（一文）: 例「和子さんの生活費・施設費の支払と、必要なら密柑山の管理・売却」
2. **受託者**と**後継受託者**（受託者が先に倒れたとき）
3. **信託するもの**と、残すもの
4. **終了**（和子さんの死亡が普通）と、残った財産の帰属（子2人なら法定相続どおりか、割合を書く）
5. **受託者報酬**（ゼロでよい）と、報告の間隔（年1回、美奈子さん・伸一郎へ収支）

信託してよいもの / 残すもの

| 入れる | 理由 |
| --- | --- |
| 密柑山の土地・建物 | 凍結すると売れない。売却が信託の本命 |
| 生活費・施設費に使う金銭 | 受託者が信託口から払う |

| 入れない・別扱い | 理由 |
| --- | --- |
| ゆうちょの口座そのもの | 信託口にできない。払戻して対応銀行へ移す。移す日は和子さん本人の判断が要る |
| 年金の受取口座 | 年金は本人名義の口座へ入る。入金後に信託口へ移す、と契約に書く |
| 日常の少額 | 全部入れると口座が一つになりすぎる。手元用は本人口座に残してよい |
| 身上（施設・医療の契約） | 信託の対象外。任意後見か家族の身元保証 |

火災保険は、登記名義が受託者に変わるので、代理店へ用途・所有者変更を出す。いま契約者は伸一郎、所有者は和子さん（[[20260913_名古屋_火災保険]]）。信託後は受託者を保険の関係者に載せる。

### 4.2 契約書に必ず書くこと

- 信託の目的
- 委託者・受託者・受益者の住所氏名
- 財産の特定（不動産は登記どおりの所在・地番・家屋番号。金銭は金額）
- 受託者の権限（管理、修繕、賃貸、**売却の可否**、売却代金の扱い）
- 禁止事項（受託者の使い込みを防ぐ。受益者のため以外に使わない）
- 分別管理（信託口口座、帳簿）
- 後継受託者
- 終了事由と残余財産の帰属
- 報告（誰に、いつ）

任意で、もう一方の子を**信託監督人**にできる。家裁の監督人ではない。報酬も契約でゼロにできる。独断売却を防ぐなら「居住用の売却は信託監督人の同意」と書く。任意後見の「監督人同意」に近いブレーキを、月額なしで付けられる。

### 4.3 書類

和子さん（委託者・受益者）: 実印、印鑑登録証明書（3か月以内）、戸籍、住民票、身分証  
受託者: 実印、印鑑登録証明書、住民票、身分証  
不動産: 登記事項証明書、固定資産税の課税明細書または評価証明書  
金銭: 預貯金の残高が分かる通帳写し

瑞穂区役所の取り方は 2.2 と同じ。不動産の証明書は名古屋市の市税事務所でも取れる。

### 4.4 手順（契約が先、口座と登記が後）


| 番号 | 手続 | 目安 |
| --- | --- | --- |
| 1 | 受託者・財産・売却の可否を家族で決める | 数日〜2週間 |
| 2 | 司法書士・弁護士に設計を頼む（推奨）。自分で文案も可 | 2〜6週間 |
| 3 | **信託口を開く銀行に、契約書案を先に見せる** | 1〜3週間。ここで落ちると作り直し |
| 4 | 公証役場で公正証書（和子さんと受託者が同席） | 予約込み2週間前後。当日は1時間前後 |
| 5 | 法務局へ「信託を原因とする所有権移転」＋「信託の登記」 | 1〜2週間 |
| 6 | 信託口口座を開き、ゆうちょ等から金銭を移す | 口座は1〜4週間。送金は和子さん本人 |
| 7 | 火災保険・固定資産税の名義・送付先を受託者側に合わせる | 契約後すぐ |

公証役場は 2.3 の名古屋駅前／熱田／葵町でよい。予約時は「民事信託（家族信託）の公正証書」と言う。公証人は和子さんの理解を確認する。通らなければ任意後見と同じで、その日は作れない。

登記の申請先は、密柑山を管轄する法務局（申請前に [名古屋法務局](https://houmukyoku.moj.go.jp/nagoya/) へ確認）。自分で出すこともできるが、信託目録の書き方を誤ると後で売れない。不動産を入れるなら司法書士が無難。

### 4.5 信託口口座（名古屋）

名義のイメージは「委託者 尾関和子 受託者 ○○ 信託口」。受託者の個人口座と混ぜてはいけない。

**ゆうちょ銀行では信託口を開けない。** いまの支払元が郵便貯金なので、家族信託にするなら、和子さんの判断が残っているうちに払戻して他行へ移す。メガバンクも信託口は少ない。名古屋・愛知で扱っている例は、十六銀行、百五銀行、三十三銀行、豊田信用金庫、碧海信用金庫、三井住友信託銀行、オリックス銀行（オンライン）など。支店・最低預入・手数料は毎回確認する。契約書案の事前審査を必須にする銀行が多い。

開けないときは、受託者名義の「この信託専用」口座を契約書で特定し、入出金を全部残す方法もある。銀行が信託と認めてくれない・受託者の死亡で凍結するリスクがあるので、次善。

### 4.6 費用の目安

| 項目 | 目安 | 払う相手 |
| --- | --- | --- |
| 設計・契約書 | 30〜80万円（財産額の約1%、最低報酬ありの事務所が多い） | 司法書士・弁護士 |
| 公正証書 | 目的価額による基本手数料 ＋ 信託加算1.3万円。合計3〜10万円が多い。謄本は別 | 公証役場 |
| 登録免許税 | 土地 評価額×0.3%（〜R11.3.31）、建物×0.4%。所有権移転（信託）側は非課税が通常 | 法務局 |
| 登記報酬 | 8〜15万円前後 | 司法書士 |
| 信託口の開設 | 0〜11万円。銀行による | 銀行 |

自分たちだけで公正証書まで行くことは法律上できる。落ちやすいのは、銀行が案を拒否する、登記の信託目録が売却に使えない、受益者を子にすると贈与税が出る、の3点。密柑山を入れるなら専門家を付ける前提でよい。

公正証書の基本手数料は目的価額の階段（[公証人手数料令](https://laws.e-gov.go.jp/law/405CO0000000224)）。例: 500万超〜1,000万は2万円、1,000万超〜3,000万は2.6万円、3,000万超〜5,000万は3.3万円。これに信託加算1.3万円。

### 4.7 始めたあとの運用

- 施設費・菊園・生活費は信託口から払う。受託者の財布と混ぜない
- 年1回、収支と残高をもう一方の子へ渡す
- 密柑山を売るときは、買主に公正証書と登記（信託目録）を見せる。契約に売却権限が書いてあることが条件
- 和子さんが亡くなると信託は終了し、残った家と金は契約の帰属先へ。相続税の申告は別途（[[20260829_相続税の計算]]）
- 判断が落ちたあとは契約を実質作り直せない。売却の可否と後継受託者は、通るうちに書く

### 4.8 次の一手（家族信託にする場合）

1. 受託者を美奈子さんにするか伸一郎にするか。もう一方を後継と信託監督人にする
2. 密柑山を入れるか。入れるなら売却権限と「監督人（もう一方）の同意」の有無
3. いくらの金銭を移すか。ゆうちょに残す生活用があるか
4. 信託口を開く銀行を先に当たり、案文の条件を聞く（十六・百五・信託銀行など）
5. 見学先のホームに、後見なしで入居契約できるかを聞く。拒むなら任意後見を足すか、契約だけ結んで発効は後回し（3.3のD）
6. 和子さんへ「家とお金の管理を子どもに託す」と短い言葉で話し、公証人の前で言えるかを見る
