# 瑞穂区・昭和区・天白区：定期巡回・随時対応型訪問介護看護

調べた日: 2026-09-14
対象: 和子さん（要介護2想定）。エリアは今の家＝総合リハビリセンター周辺（瑞穂／昭和／天白）。美奈子さんの休息・夜間・夕食セットの穴埋め用。介護保険内。

## 結論

定期巡回は**介護保険の24時間訪問**。決まった時間に短時間で何度も入り、コールがあれば随時も来る。月額定額なので、訪問回数が増えても基本料は同じ。要介護1〜5のみ。要支援は不可。名古屋市の住民票が必要（地域密着型）。申込は谷津さん経由。

密柑山（瑞穂区）で先に聞くなら、公式に瑞穂区がある**リンクケア定期巡回**と、利用者44人の実績がある**ライフケアサポート名古屋**。かわな病院系列の**定期巡回かわな**は一体型で医療が厚いが、提供地域は昭和区のみ。密柑山は瑞穂区なので原則対象外。

訪問は短時間（目安10〜20分）が中心。夕食の取り出し・服薬・トイレ誘導には合う。本格的な調理や長時間見守りは、いまの**菊園**や検討中の**イチロウ**（いずれも保険外）と分ける。保険の訪問介護・訪問看護とは併用できない。デイ・ショートは併用可（減算または日割り）。

表は区ごと。新規が多くレーダーは未掲載が多いので、並びは**利用者数が多い順**。ホームページが無い場合は「なし」。調べた日2026-09-14。出典は [名古屋市](https://www.kaigo-wel.city.nagoya.jp/view/kaigo/service/jitaku/teiki.html)、[介護サービス情報公表システム](https://www.kaigokensaku.mhlw.go.jp/23/index.php?action_kouhyou_pref_topjigyosyo_index=true)、[ハートページ（2026年7月）](https://www.heartpage.jp/nagoya/list?type=visit_nursing_care_any_time)。

## 制度の要点

4つの組み合わせ。定期巡回（決まった短時間訪問）＋随時対応（24時間の電話）＋必要なら随時訪問＋必要なら訪問看護。

| 項目 | 内容 |
| --- | --- |
| 対象 | 要介護1〜5。要支援不可。名古屋市の住民票が必要 |
| 料金 | 月額定額。回数を増やしても基本料は同じ |
| 要介護2・1割の目安 | 看護なし約9,720円／看護あり約12,413円（厚労省の単位＝10円換算）。名古屋市は3級地（1単位11.05円）＋処遇改善等で、実額は看護なし約1.1〜1.4万円、看護あり約1.4〜1.8万円 |
| 併用不可 | 訪問介護（通院等乗降介助は除く）、介護保険の訪問看護、夜間対応型訪問介護 |
| 併用可 | デイ・通所リハ（利用日は定期巡回が減算）、ショート（入所中は日割り）、福祉用具、居宅療養管理指導、保険外（菊園・イチロウ） |
| 一体型／連携型 | 一体型は事業所内に看護。連携型は提携の訪問看護。密柑山周辺の実績店は連携型が多い |

いま訪問介護（保険）を使っているなら、定期巡回に切り替える形になる。使っていなければ、そのまま足せる。

## イチロウ・菊園との役割分担

保険外まとめは [20260904_名古屋_介護保険外サービス](20260904_名古屋_介護保険外サービス.md)。


| 用途 | 向くもの | 理由 |
| --- | --- | --- |
| 短時間の複数回（食事セット、服薬、トイレ、夜間コール） | 定期巡回 | 保険。月額定額。24時間 |
| 水曜の食事づくり | 菊園（利用中） | 保険外。料理は3時間〜 |
| 穴埋めの2時間以上（夕食準備の試し、見守り） | イチロウ | 保険外。最低2時間。定期巡回と併用可 |
| 医療寄り・看取り | かわな（昭和区のみ）またはサンゲール | かわなは保険の一体型。密柑山はエリア外の可能性 |

定期巡回を入れると、保険の訪問介護は止めになる。菊園とイチロウは止めなくてよい。
