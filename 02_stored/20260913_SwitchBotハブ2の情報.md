# SwitchBot ハブ2の情報

調べた日: 2026-09-13  
対象: 赤外線リモコン付きエアコン／テレビ。密柑山では居間ハブがテレビ・クーラー、寝室ハブがクーラー（[[11_名古屋/20260922_名古屋やること]]）。Wi-Fiは **2.4GHz** 必須（[[wifi中継について]]）。

ハブ2は赤外線リモコン＋温湿度計。エアコンとテレビは「リモコンを学習」してから操作する。温度で自動ON/OFFは、学習したエアコンをオートメーションに載せる。

アプリの文言は版で少し違う。近い項目を選ぶ。

## 先にやること（ハブ2本体）

1. SwitchBotアプリを入れ、アカウントを作る
2. ハブ2を付属アダプタで電源につなぐ。エアコンとテレビの**受光部（本体の窓）が見える場所**に置く
3. ホーム右上「＋」→「ハブ2」。案内どおり本体ボタンを押し、**2.4GHz** のSSIDとパスワードを入れる（5GHzだけだと繋がらない）
4. 名前を付ける（例: 居間ハブ／寝室ハブ）

学習するとき、手元リモコンはハブ2に **数cm〜十数cm** まで近づけ、ボタンは短く1回。電池が弱いと失敗する。

## 1. リモコンでエアコンを操作する

1. ホームでハブ2を開く →「リモコンを追加」（赤外線の「＋」）
2. 「エアコン」を選ぶ
3. 先に「リモコンの自動学習」（スマートラーニング）
4. エアコンのリモコンをハブ2に向け、「今すぐ開始」のあと **電源ボタンを1回**
5. 候補が出たら、アプリの電源で実機が動くか試す。動かなければ「動かない」で次の候補
6. 自動で見つからなければ、メーカーを手で選ぶ。それでもダメならボタンを1つずつ学習
7. 名前を付ける（例: 居間エアコン）。ホームのエアコンを開き、電源・冷房／暖房・温度・風量を試す

エアコンはモードと温度まで出せる。元リモコンのタイマーはハブ2からは出ないことが多い。時間で切りたいときはオートメーションかスケジュールにする。

ハブ2は一部機種で、手元リモコンの操作をアプリに同期できる。物理リモコンとアプリを両方使うなら、ハブ2がリモコン信号を受け取れる位置に置く。

---

## 2. リモコンでテレビを操作する

流れはエアコンと同じ。種類だけ「テレビ」。

1. ハブ2 →「リモコンを追加」→「テレビ」
2. 自動学習。リモコンを近づけて電源ボタンを1回
3. アプリの電源でテレビが付くか確認。ダメならメーカー選択、その次はボタン学習
4. 名前（例: 居間テレビ）。電源・音量・チャンネル・入力切替を試す

テレビはメーカー差が大きい。電源だけ動けば、音量やチャンネルはボタン学習で足す。ハブ2からテレビの受光部（だいたい下部や枠）へ赤外線が届くこと。

### 地デジ／BS／CSの切替

手元リモコンで切り替えられるなら、ハブ2でもできる。公式の学習リモコンでも、テレビの入力切換に地デジ（DTTV）・BS・CS/CATVがある。[学習リモコンで操作できる機能](https://blog.switchbot.jp/top/devices-and-functions-universal-remote/)

1. 自動学習やメーカー選択のあとに、アプリのテレビ画面に「地デジ」「BS」「CS」や「放送切替」があるか見る
2. 無い、または押しても変わらないときは、そのテレビを開き「ボタン学習」（または「その他」でボタンを追加）
3. ハブ2にリモコンを近づけ、実機の **地デジ** → 学習 → テスト。同じことを **BS**、**CS** でもする
4. ボタン名は `地デジ` `BS` `CS` にしておく。よく見る局は `BS1` のように、放送切替＋番号を1ボタンに学習してもよい

注意

- テレビ内蔵チューナーなら、テレビリモコンだけで足りることが多い
- CSや一部BSが外付けチューナー／レコーダー経由なら、**その機器のリモコンも**ハブ2に別登録する
- 「入力切替」はHDMIとチューナーを巡るだけ、の機種がある。放送波の切替は地デジ／BS／CSボタンを学習する
- チャンネル番号は、先に放送波を切り替えてから押す。地デジの1とBSの1は別信号のことが多い

## 3. 温度を見てエアコンを自動ON/OFFする

先に §1 でエアコンがアプリから動くこと。温度は**ハブ2本体のセンサー**を使う（同じ部屋に置く。日向・エアコンの風の直撃は避ける）。

ONとOFFは**別々のオートメーション**にする。同じ温度にすると、境目で付き消しが続く。

例（夏・冷房）: **28℃以上でON**、**25℃以下でOFF**（差は2〜3℃）。

### ON

1. 下の「オートメーション」（またはホーム右上「＋」→「オートメーションを追加」）
2. 名前: `暑くなったら冷房`
3. 「いつ」→「条件を追加」→「デバイスの状態」→ その部屋のハブ2 → 温度が **28℃以上**
4. 「実行」→「アクションを追加」→「デバイス」→ 登録したエアコン → **冷房・26℃・電源ON**（数字は部屋に合わせる）
5. 最初は実行通知をONにして保存

### OFF

1. 同じ手順で名前: `涼しくなったら切る`
2. 条件: 同じハブ2の温度が **25℃以下**
3. アクション: 同じエアコンの **電源OFF**
4. 保存

冬は「18℃以下で暖房ON」「22℃以上でOFF」のように、向きを逆にする。

### 注意

- 赤外線は「押したつもり」なので、届かないと実機は動かない。届く位置か、アプリから手動で一度確認する
- すでにエアコンが付いているときにONを送ると、機種によっては消える（トグル）。状態同期が使える機種はズレにくい
- 公式の「パーソナライズエコ」でも室温に合わせて制御できる。既存の温度オートメーションがあるときは、公式案内どおり先に無効にする。アプリと本体ファームは案内の版以上（記事時点でアプリ v9.13以上）
- 消し忘れ防止は、温度OFFに加えて「毎日23:00にOFF」のスケジュールも使える

## 密柑山での置き方

| 場所 | ハブ | 登録するもの |
| --- | --- | --- |
| 居間 | 居間ハブ | テレビ、クーラー |
| 寝室 | 寝室ハブ | クーラー（照明も可） |

温度連動は、**その部屋のハブの温度**で、**その部屋のエアコン**を動かす。居間の温度で寝室を切らない。
