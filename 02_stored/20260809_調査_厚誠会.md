# 調査報告書: 医療法人社団厚誠会

- 調査日: 2026-08-09
- 対象: 医療法人社団厚誠会（通称: 厚誠会／厚誠会歯科グループ）

- 調査焦点: 公開情報に基づく法人の実在性・事業内容・信頼性の基礎確認

## 1. エグゼクティブサマリー

「厚誠会」は、神奈川県を中心に小田急線沿線で歯科医院を運営する **医療法人社団厚誠会**（法人番号: 4021005003453）を指すと特定できる。公式サイト・国税庁法人番号公表サイト・関東信越厚生局データを基にした第三者掲載で、実在する医療法人・保険医療機関であることが確認できる。現在は新百合ヶ丘・相模大野・海老名・本厚木・秦野の5医院と訪問診療を掲げ、2026年5月に主たる事務所を相模大野へ変更、2024〜2026年に理事長が複数回交代している。本調査範囲では行政処分や重大トラブルの報道は見つからなかった。総合評価は「公開一次情報で実在・事業内容は確認でき、信頼の土台はある。ただし理事長交代の頻度と口コミは個別受診判断の補足材料」。

## 6. 疑わしい点・矛盾

- **同名別法人の存在**: 八王子の「医療法人社団厚誠会」（7010105000706）と混同しやすい。今回の対象は神奈川の歯科法人（4021005003453）
- **理事長の短期間交代**: 公式沿革上、2016年有馬正英 → 2024年12月有馬嗣雄 → 2025年7月大山慶子 → 2026年7月黒木良。交代自体は違法性を意味しないが、外部から見るとガバナンス変化が大きい
- **開設者表記のタイムラグ**: 本厚木のオープンデータ（2026年7月更新表記）では開設者に「理事長 大山 慶子」、公式沿革では2026年7月に黒木良就任。データの更新遅れの可能性
- **所在地の最近の変更**: 2026年5月に厚木→相模大野。相模大野医院所在と法人事務所の一致は合理的だが、古い住所表記の二次情報が残っている
- **料金情報の不一致（Vault）**: 厚誠クラブチラシと EPARK 掲載料金が一致しない点を利用者が記録。Web二次情報の料金は要一次確認
- **「神奈川県第一号として歯科往診」等の歴史的主張**: 公式記載。独立した公的史料での裏付けは本調査未実施
