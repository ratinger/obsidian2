> Windowsでwhichllmをインストール・実行する手順
<!-- vault-seiri:end -->

[whichllm](https://github.com/Andyyyy64/whichllm) は、PCのGPU/CPU/RAMを検出し、ハードウェア上で動くローカルLLMをベンチマーク付きでランキングするCLIツール。

## 前提

- Python 3.11 以上（このPC: Python 3.13.3）
- [uv](https://docs.astral.sh/uv/)（このPC: uv 0.8.x）

## インストール

永続インストール（推奨）:

```powershell
uv tool install whichllm
```

インストール先: `C:\Users\ozeki\.local\bin\whichllm.exe`

アップデート:

```powershell
uv tool upgrade whichllm
```

一時実行（インストール不要）:

```powershell
uvx whichllm@latest
```

## 実行

PowerShell または Windows Terminal で:

```powershell
whichllm
```

## Windows での文字コード対策

cp932 環境では `UnicodeEncodeError` が出ることがある。実行前に UTF-8 を設定する:

```powershell
$env:PYTHONUTF8=1
$env:PYTHONIOENCODING="utf-8"
chcp 65001
whichllm
```

毎回設定する場合は PowerShell プロファイル（`$PROFILE`）に上記3行を追加する。

## よく使うコマンド

```powershell
whichllm --json              # JSON出力（スクリプト向け）
whichllm --top 5             # 上位5件だけ表示
whichllm run                 # おすすめモデルでチャット
whichllm plan "llama 3 70b"  # 特定モデルに必要なGPUを調べる
whichllm --gpu "RTX 4090"    # GPUを指定してシミュレーション
whichllm upgrade "RTX 4090" "RTX 5090"  # GPUアップグレード比較
whichllm --help              # ヘルプ
```

## このPCの検出結果（2026-06-27時点）

| 項目 | 内容 |
|------|------|
| GPU | Intel Iris Xe Graphics（共有メモリ） |
| CPU | 12th Gen Intel Core i7-1260P（12コア） |
| RAM | 約 15.7 GB |
| 実行ファイル | `C:\Users\ozeki\.local\bin\whichllm.exe` |

おすすめ1位: **Qwen/Qwen3-14B**（Q5_K_M、約11.7 GB VRAM）。内蔵GPUのため推定速度は低めと表示される。

## Ollama と組み合わせる場合

1. [Ollama](https://ollama.com/) をインストール
2. `whichllm` でおすすめモデルを確認
3. `ollama pull <モデル名>` で取得
4. `ollama serve` で API 起動（`localhost:11434`）
