# 無人PC（TeamViewer）向け 自動ログイン設定メモ

## 目的

実家PCなどの無人運用で、**Windows Update後に「ログイン待ち」で止まり、TeamViewerにつながらなくなるリスクを減らす**。

---

# 1. サインインオプションの確認

まず、Windows Update後に自動的に続きを完了しやすくする設定を確認する。

## 開き方

**設定 → アカウント → サインイン オプション**

確認する項目：

### ① 更新後に自動的にセットアップを完了する

以下を **ON**

> 更新後に自動的にセットアップを完了するには、サインイン情報を使用します

意味：

Windows Update後の再起動時に、保存されたサインイン情報を使って内部的にログインし、更新処理を完了しやすくする。

**効果**
- Update後の止まりを減らせる
- TeamViewerが起動しやすくなる

ただし、大型アップデートなどでは止まることもある。

---

### ② Windows Hello の設定（重要）

もし `netplwiz` のチェックボックスが出ない場合：

以下を **OFF**

> セキュリティ向上のため、このデバイスでは Microsoft アカウントに Windows Hello サインインのみを許可する（推奨）

これをOFFにすると、後述の **自動ログイン設定のチェックボックス** が表示されることがある。

---

# 2. 自動ログイン設定（重要）

## 手順

### 1. 実行を開く

`Win + R`

### 2. 以下を入力

```text
netplwiz
```

### 3. ユーザー設定画面で確認

以下のチェックを外す：

> ユーザーがこのコンピューターを使うには、ユーザー名とパスワードの入力が必要

### 4. 「適用」

パスワード入力を求められるので入力。

- Microsoftアカウントの場合 → Microsoftアカウントのパスワード
- ローカルアカウントの場合 → Windowsログインパスワード

### 5. 再起動して確認

正常なら、Windows起動後に **自動でログイン** する。

---

# 3. TeamViewer 側の設定

## Windows起動時に開始

TeamViewer を開く

**設定 → 一般**

以下を **ON**

> Windowsと同時にTeamViewerを開始

---

## 無人アクセス

TeamViewerアカウントにログインし、

**無人アクセス** を有効化しておく。

確認項目：

- TeamViewerアカウントでログイン済み
- デバイスがアカウントに紐付いている
- パスワード設定済み

---

# 4. 電源設定（おすすめ）

## スリープ OFF

**設定 → 電源**

以下を無効化：

- スリープ
- 自動休止

理由：

スリープ状態だと TeamViewer に接続できないことがある。

---

## BIOS の停電復帰（できれば）

設定名の例：

- Restore on AC Power Loss
- AC Power Recovery
- Power On After Power Loss

これを **ON**

意味：

コンセント電源が戻った時に、自動でPCが起動する。

SwitchBotコンセント運用と相性が良い。

---

# 5. 今回のトラブルの原因候補

症状：

> 電源ON後、いつもなら数分でTeamViewerにつながるのに来ない

可能性（優先順）

1. Windows Update途中で止まった
2. TeamViewerサービス停止
3. TeamViewer自動起動が外れた
4. 更新後の確認画面で停止
5. 自動修復モード

よくある停止画面：

- 更新しています
- ようこそ
- PCを準備しています
- 更新を完了しています
- プライバシー設定
- PIN設定確認

---

# 6. 実家でやることチェックリスト

- [ ] サインインオプション確認
- [ ] 更新後の自動サインイン設定 ON
- [ ] Windows Hello 制限 OFF（必要なら）
- [ ] `netplwiz` 設定
- [ ] 自動ログイン確認
- [ ] TeamViewer自動起動 ON
- [ ] 無人アクセス確認
- [ ] スリープ OFF
- [ ] 再起動して接続テスト

---

# メモ

無人PC運用では、

**「自動ログイン + TeamViewer自動起動 + スリープOFF」**

の3点セットがかなり効く。

SwitchBotでコンセント断を使う場合は、Windows Update中に止まる可能性があるので注意。
