# PCのイヤホン・マイクでスマホの携帯電話を使う

作成日: 2026-08-12  
目的: スマホのイヤホンマイクを忘れても、PC側のイヤホン／マイクで通話する

前提: **Windows PC + Android**（Pixel 想定）。iPhone は通話連携不可。

---

## 結論（いちばん簡単）

Windows の **スマートフォン連携（Phone Link）** を使う。

- 通話そのものはスマホの回線
- 声の入出力は **PCに刺したイヤホン・マイク**
- 着信も PC に出るので、スマホを手に取らなくてよい

---

## 事前確認（PCの音声）

通話前に、Windows の入出力が PC イヤホンになっているか見る。

1. **設定 → システム → サウンド**
2. **出力**: 使いたいイヤホン／ヘッドホン
3. **入力**: 使いたいマイク（イヤホン一体型ならそのマイク）
4. **マイク権限**（この画面で合っている）
   1. 「アプリがマイクにアクセスすることを許可する」が **オン**（スクショどおりでOK）
   2. アプリ一覧を **下へスクロール**し、**スマートフォン連携**（Phone Link）を **オン**
   3. 一覧に無いときは、さらに下の  
      **「デスクトップ アプリがマイクにアクセスすることを許可する」** も **オン**
   4. それでも無いときは、いったん **スタート → スマートフォン連携** を開いて通話を試す  
      → 初回アクセス後に一覧へ出てくることがある

タスクバーのスピーカーアイコンを右クリック →「サウンド設定を開く」で、上記 1〜3（入出力）まで開ける。マイク権限は別画面。

---

## 初回セットアップ

### PC側

1. スタートから **スマートフォン連携**（Phone Link）を開く
2. **Android** を選ぶ
3. 表示された QR をスマホで読む（案内に従う）

### スマホ側

1. **Windows にリンク**（Link to Windows）を入れる／開く
2. Microsoft アカウントでログイン（PCと同じでよい）
3. 権限をすべて許可する  
   - 電話 / 通話  
   - 連絡先  
   - 通知  
   - マイク（求められる場合）

### Bluetooth（通話に必須）

Phone Link の **通話** は Bluetooth 経由。

1. PC・スマホとも Bluetooth ON
2. Phone Link の案内どおりペアリング（または Windows の Bluetooth 設定でペア）
3. Phone Link 左メニューの **通話** が使える状態になるまで待つ

Wi-Fi だけでは通知・写真などは動いても、**通話は Bluetooth が必要**。

---

## 使い方

### 発信

1. PC で **スマートフォン連携** を開く
2. **通話** → キーパッド or 連絡先
3. 発信 → 声は PC イヤホン／マイクで通る

### 着信

1. PC に着信ポップアップが出る
2. PC から応答
3. そのまま PC イヤホンで話す

---

## うまくいかないとき

| 症状 | 確認 |
| --- | --- |
| 通話タブが使えない | Bluetooth 接続切れ。両方 ON・再ペア |
| 相手の声が聞こえない | サウンドの **出力** がイヤホンになっているか |
| 自分の声が届かない | サウンドの **入力** が正しいマイクか／Phone Link のマイク許可 |
| 着信が PC に出ない | スマホ「Windows にリンク」で通話・通知を有効／電話権限 |
| いきなり切れる | PC とスマホを近くに置く。省電力で Bluetooth が落ちていないか |

## 通話録音

**スマートフォン連携に録音ボタンはない。** PC 経由で通話しているときだけ、PC 側ソフトで録れる。

### OBS で録る（相手＋自分）

ダウンロード: [OBS Studio 公式](https://obsproject.com/ja/download)（Windows）

#### 1. 初回セットアップ（初回だけ）

1. OBS を起動。ウィザードが出たら **最適化はスキップでも可**（配信しないなら）
2. 右下の **設定** を開く
3. 左の **音声**
   - **デスクトップ音声**: 使っているイヤホン／ヘッドホン（または「既定」）
   - **マイク音声**: 使っているマイク（イヤホン一体型ならそれ）
   - 「無効」になっていたら、上のようにデバイス名を選ぶ
4. 左の **出力**
   - **録画パス**: 保存したいフォルダ（例: `ドキュメント\通話録音`）
   - **録画フォーマット**: `mkv` 推奨（落ちても壊れにくい。後で mp4 に変換可）
5. **適用 → OK**

画面（映像）は黒のままでよい。今回は音声だけ使えれば十分。

#### 2. メーターで音が入るか確認

メイン画面下の **音声ミキサー** を見る。

| 項目 | 何の音 | 確認方法 |
| --- | --- | --- |
| デスクトップ音声 | 相手の声（PCから出る音） | YouTube などを一瞬再生 → 緑のバーが動く |
| マイク音声 | 自分の声 | 話しかけてバーが動く |

動かないとき:

- Windows **設定 → システム → サウンド** の出力／入力が、いま使うイヤホン・マイクか
- OBS の音声で選んだデバイス名がそれと同じか
- 音声ミキサーのスピーカーアイコンが赤（ミュート）になっていないか

#### 3. テスト録音（本通話の前に必須）

1. OBS で **録画開始**
2. スマホ連携で短いテスト発信（または自分の別番号など）し、数秒話す
3. **録画停止**
4. 録画パスのフォルダを開き、再生して **相手＋自分** が入っているか確認

#### 4. 本番の流れ

1. OBS を開いたまま **録画開始**
2. **スマートフォン連携** で発信／着信して通話
3. 終わったら OBS で **録画停止**
4. 録画パスのフォルダにファイルができる

※ 録画中は OBS を閉じない。最小化は可。

#### 5. mkv → mp4 にしたいとき（任意）

OBS メニュー **ファイル → 録画の再多重化**  
→ mkv を選ぶ → 同じフォルダに mp4 ができる（再エンコードしないので速い）。

#### うまくいかないとき（OBS）

| 症状 | 対処 |
| --- | --- |
| 自分の声だけ入る | デスクトップ音声が無効／ミュート。デバイスを選び直す |
| 相手の声だけ入る | マイク音声のデバイス間違い／ミュート／Windows のマイク許可 |
| 音が二重・エコー | 「アプリケーション音声キャプチャ」とデスクトップ音声を両方入れていないか。片方だけでよい |
| Phone Link だけ録りたい | ソースの **＋ → アプリケーション音声キャプチャ** で Phone Link／スマートフォン連携を選ぶ。その場合は設定のデスクトップ音声を **無効** にして二重録音を防ぐ |
| ファイルが見つからない | 設定 → 出力 → 録画パスを確認 |

※ Windows 標準の「サウンド レコーダー」は **マイクだけ** になりがちで、相手の声が入らないことが多い。

### しっかり（音声ルーティング）

VoiceMeeter などで「相手の声＋マイク」を1本に混ぜてから録音する。設定は少し手間。

### 注意

- 相手への説明・同意は状況に応じて取る（特に仕事・第三者の話）
- Pixel 本体の通話録音は地域・機種で制限されやすく、期待しにくい
- 録音ファイルは個人情報扱いで保存先に注意

---

## 代替（Phone Link が使えないとき）

1. **スマホに Bluetooth イヤホンを直接ペア**（PC経由ではないが、手元に Bluetooth 機があれば可）
2. **PC イヤホンをスマホに直挿し**（端子が合う場合のみ。Type-C 変換が要る機種あり）
3. スピーカーフォンでスマホ本体マイクを使う（周囲に音が漏れる）

---

## メモ

- 回線はスマホ側。PC はリモコン＋ヘッドセット代わり
- 初回だけ設定が面倒。一度つながれば次回は Bluetooth と Phone Link を開くだけで使える
