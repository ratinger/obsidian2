# Brave Talkの会議を文字起こしする（OBS・音声のみ）

作成日: 2026-08-25
用途: 名古屋とのWeb会議（谷津さんなど）

Brave Talkはそのまま使う。録音は OBS。映像は不要。
会議の最初に「文字起こしのために録音します」と一言入れる。

手動の順: **1章 → 備考１ → 2章**。自動化は 1章と備考１のあと **3章**（`/6_gijiroku`）。

文字起こしは **Python から `gemini-3.5-transcribe`** を呼ぶ。`gemini` コマンド（CLI）ではこのモデルは使えない。

**音声と文字起こしは Vault の外。議事録だけ `11_名古屋`。**

| 種類 | フォルダ名 | ファイル名 |
| --- | --- | --- |
| 音声（元） | `C:\Users\ozeki\Videos\Web会議\YYYYMMDD` | `YYYYMMDD_HHMMSS.mkv` |
| 音声（変換） | 同じ | `YYYYMMDD_HHMMSS.mp3`（1本のとき） |
| 音声（分割） | 同じ | `part0.mp3` / `part1.mp3` / `part2.mp3`（15分単位） |
| 文字起こし | 同じ | `YYYYMMDD_相手_文字起こし.md` |
| 議事録 | `11_名古屋` | `YYYYMMDD_相手_議事録.md` |

議事録から文字起こしへはフルパス（`[[リンク]]` は使わない）。

## 1章 事前

会議の前に1回やるセットアップと、当日の録画。

1. [OBS Studio](https://obsproject.com/ja/download) を入れる
2. 起動したら、ソースは映像を足さない。次の2つだけ足す
   - **音声出力キャプチャ** … 相手の声（デスクトップ音声）
   - **音声入力キャプチャ** … 自分の声（マイク）
3. 設定 → 出力 → **録画**
   - 録画パスは **ビデオ\Web会議**（`C:\Users\ozeki\Videos\Web会議`）
   - 録画フォーマットは **Matroska Video (.mkv)**
   - この画面に m4a は出ない。映像ソースが空でも、mkv の中に音声が入る。途中で落ちてもファイルが壊れにくい
4. 設定 → **詳細設定** → **ファイル名の書式** は `%CCYY%MM%DD_%hh%mm%ss`（例: `20260828_165302.mkv`）。**このPCは 2026-08-30 に設定済み。** eMeet の音声設定は触らない
5. 設定 → **音声** で、デスクトップ音声とマイクを、いま会議で使うスピーカー／マイクと同じにする（このPCの会議用は **eMeet M0**）
6. 下部のレベルメーターで、自分が話したときと、Braveのテスト音の両方が振れるか見る
7. 「録画開始」で30秒録って止め、ファイルが再生できるか確認する（相手＋自分）

保存先の親は **ビデオ\Web会議**。録ったあと、日付フォルダ `YYYYMMDD` を作り、mkv を移す。

両方のメーターが振れないときは、ソースのデバイスが「規定」や今使っているスピーカー／マイクになっているか見る。イヤホン使用時も、出力キャプチャはデスクトップ音声のまま。Windowsの出力先と OBS のデスクトップ音声が違うと、相手が無音になる。

### 会議当日

1. 開始時に「文字起こしのために録音します」と了解をとる
2. Brave Talk に入る
3. OBS で「録画開始」（**録画中は OBS を閉じない**。最小化は可）
4. 会議する
5. 「録画停止」
6. `C:\Users\ozeki\Videos\Web会議` に `.mkv` ができているか、再生して両方の声が入っているかを確認する
7. 日付フォルダ `C:\Users\ozeki\Videos\Web会議\YYYYMMDD` を作り、mkv を移す（例: `20260828\20260828_165302.mkv`）

## 備考１

`gemini-3.5-transcribe` の準備（会議の前に1回）。Python から Interactions API を叩く。ここまでできてから 2章へ。

1. **ffmpeg** があること（`ffmpeg -version`）。mkv → mp3 に使う
2. **Python 3**（このPCは 3.13）と SDK

```powershell
pip install -U google-genai
```

3. [Google AI Studio の APIキー](https://aistudio.google.com/apikey) を作る
   - 先に Cloud プロジェクトが要る。無いと「キーを作成」が押せない
   - Brave だと「The request is suspicious」になることがある。盾を切るか Chrome で作る
   - プロジェクト名は `gemini-api` のような汎用名より、自分用の名前にする
4. キーを `%USERPROFILE%\.gemini\.env` に書く（git に入れない）

```
GEMINI_API_KEY=ここにキー
```

5. 短い mp3 で、専用モデルが通るか見る。成功の目安は日本語（このPCの5秒テストは「こんにちは。」）。試験用の `test.mp3` は 2026-08-30 に消した。次に試すときは短い音を録り、パスを合わせて叩く

```powershell
python .cursor/skills/6-gijiroku/scripts/transcribe.py "C:\Users\ozeki\Videos\Web会議\短い試験.mp3"
```

プログラムの場所: `.cursor/skills/6-gijiroku/scripts/transcribe.py`（`1_seiri` の `scripts/` と同じ置き方）

6. 話者名と時刻は、スクリプトが **verbatim + 話者識別 + 単語時刻** を付けたときだけ出る。付けないと本文だけになる（`00_temporary` の8/28は識別あり、Skill初回は識別なし）
7. 話者識別付きは1本あたり約30分が上限。**15分単位** で分割する。無料枠の入力トークン上限に注意
8. 会議音声は個人情報。`.env` と録音は共有しない

## 2章 文字起こし

備考１ができている前提。作業は **日付フォルダ** で行う。

```powershell
cd "C:\Users\ozeki\Videos\Web会議\20260828"
```

| 種類 | フォルダ名 | ファイル名 |
| --- | --- | --- |
| 音声（元） | `C:\Users\ozeki\Videos\Web会議\YYYYMMDD` | `YYYYMMDD_HHMMSS.mkv` |
| 音声（変換） | 同じ | `YYYYMMDD_HHMMSS.mp3`（1本のとき） |
| 音声（分割） | 同じ | `part0.mp3` / `part1.mp3` / `part2.mp3`（15分単位） |
| 文字起こし | 同じ | `YYYYMMDD_相手_文字起こし.md` |
| 議事録 | `11_名古屋` | `YYYYMMDD_相手_議事録.md` |

mkv / mp3 / 文字起こしは Vault にコピーしない。議事録だけ Vault。

1. 対象の `.mkv` を mp3 にする（ファイル名は実際のものに替える）

```powershell
ffmpeg -i "20260828_165302.mkv" -vn -acodec libmp3lame "20260828_165302.mp3"
```

2. **15分（900秒）を超える会議は分割**する（15分＋15分＋残り）

```powershell
ffmpeg -i "20260828_165302.mkv" -vn -ss 0 -t 900 -acodec libmp3lame "part0.mp3"
ffmpeg -i "20260828_165302.mkv" -vn -ss 900 -t 900 -acodec libmp3lame "part1.mp3"
ffmpeg -i "20260828_165302.mkv" -vn -ss 1800 -acodec libmp3lame "part2.mp3"
```

3. Skill 配下のスクリプトで起こす（`gemini` コマンドは使わない）

```powershell
python .cursor/skills/6-gijiroku/scripts/transcribe.py "C:\Users\ozeki\Videos\Web会議\20260828\part0.mp3" -o "C:\Users\ozeki\Videos\Web会議\20260828\part0_文字起こし.txt"
```

分割していれば `part1.mp3` も同じ。Vault ルートで実行する。
4. 画面に出たテキストを、**同じ日付フォルダ** に残す
   - 場所: `C:\Users\ozeki\Videos\Web会議\YYYYMMDD`
   - 名前: `YYYYMMDD_相手_文字起こし.md`（例: `20260828_谷津さん_文字起こし.md`）
5. 分割したときは、2本を **1つのファイルにこの順でつなぐ**。後半の時刻は、切れ目（例: 25:00）を足して読む
6. 話者が分かれていれば人名に割り当てる（例: 伸一郎／谷津さん／母親）。途中で入れ替わることがある
7. 議事録は `11_名古屋/YYYYMMDD_相手_議事録.md` に書く。文字起こしへはフルパス（`[[リンク]]` は使わない）

文字起こしの先頭:

```
# YYYY-MM-DD 相手とのテレビ会議（文字起こし）

日時:
参加者:
元録音: `C:\Users\ozeki\Videos\Web会議\YYYYMMDD\YYYYMMDD_HHMMSS.mkv`
文字起こし: Gemini 3.5 Transcribe（Python）
```

### 動いたときの流れ

0. **最初に止まる。** 今回は Web会議か電話かを聞く。種類が分かったら、議事録で考慮することを聞く（参加者、相手名、強調／除外）。答えが来るまで文字起こしに入らない。Web会議の相手名がなければ **谷津さん**。電話なら **栞さん**
1. Web会議なら `C:\Users\ozeki\Videos\Web会議` 配下の最新 `.mkv` を取る。電話なら `C:\Users\ozeki\Videos\電話` の最新 `.mp3`。無ければ止める。直下に残っていれば `YYYYMMDD` フォルダを作り移してから進む
2. 長さを見て、15分超なら 2章どおり 15分単位に分割する。mp3 は **mkv と同じ日付フォルダ** に置く
3. `ffmpeg` で mp3 にし、`scripts/transcribe.py` で起こす
4. 話者ラベルを人名に割り当てる（名古屋の定例は 伸一郎／谷津さん／母親）
5. 分割していれば1ファイルにこの順でつなぐ
6. **文字起こし** は日付フォルダへ。**議事録** だけ `11_名古屋/` へ書く
