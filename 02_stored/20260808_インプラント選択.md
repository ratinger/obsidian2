# インプラント選択

上顎左7番の抜歯後インプラントについて、メーカー名だけで決めず、骨条件→治療計画→価格差の順で比べるためのメモ。

---

## 1. いまの条件

- 対象：上顎左7番（上顎第二大臼歯）
- 虫歯のため抜歯予定。抜歯後の選択肢としてインプラントを検討
- CT測定：歯槽骨頂から上顎洞底（じょうがくどうてい）まで **6.58 mm**
- 以前の説明：インプラント長 **7 mm**
- 提示費用：
  - **MegaGen：約35万円（込み込み）**
  - **他メーカー：約70万円**
- 35万円が安い理由（医院側の説明）：**最近導入して試験的に使っているため。しばらくすると高くなる**
- 体制（聞いている範囲）：担当の先生とは別に、**慣れた大学の先生が同席する**らしい

判断の焦点は、「35万円のMegaGenか、70万円の他メーカーか」。価格差は「永久に安い製品」ではなく、**導入初期の試験価格**である点に注意。経験面は、大学の先生の同席があればかなり補える。

---

## 2. 選択の考え方

### 6.58 mm と 7 mm は単純対応ではない

「骨高6.58 mmだから7 mmを入れる」とは限らない。実際は次を総合して決める。

- インプラントの長さ・直径
- 埋入位置・角度
- 骨の幅・骨質
- 初期固定をどこで得るか
- 上顎洞底挙上（きょじょう。サイナスリフト等）の要否
- 使用するインプラントシステム

### MegaGenについて

以前話題になったのは次の2系統。

| 系統 | 特徴 |
|---|---|
| AnyRidge | 強い初期固定を狙う設計。骨量が少ないケースや短いインプラントの候補になりやすい |
| AnyOne | より標準的な設計。AnyRidgeより単純に劣るわけではない |

今回の製品が **AnyRidge か AnyOne か** は、歯科医師に確認する。

### メーカーより先に見るもの

MegaGenは実績のないメーカーではない。Straumann、Nobel Biocare、Astra Tech（Dentsply Sirona）などは長期臨床データ・世界的使用実績が特に厚い。

ただし「有名メーカーなら長期成績が必ず大幅に良い」とは言い切れない。優先順位は次の順。

1. 歯科医師の経験・症例数
2. 骨の状態と治療計画
3. 埋入技術
4. メンテナンス体制
5. 使用メーカー

### 短いインプラントはMegaGenだけではない

大手にも6 mm前後のショートインプラントはある。

> 「MegaGenだから短いインプラントが使える」ではなく、「6.58 mmの骨高に対して、各メーカーの何mmを、どんな計画で使うか」が本質。

比較の順番：

**骨高6.58 mm → 長さ・直径 → 上顎洞への対応 → どのメーカーで行うか → 35万と70万の差は何か**

## 3. 35万 vs 70万の見極め方

| 項目 | MegaGen | 他メーカー |
|---|---:|---:|
| 費用 | 約35万円 | 約70万円 |
| 価格差 | - | 約35万円 |
| 長期実績・データの厚み | ○ | ◎（メーカーによる） |
| 検討価値 | 高い | 価格差に見合うか要確認 |

聞くべき核は次の一文。

> **70万円にすることで、具体的に何が35万円分変わるのか？**

「メーカーの信頼性が違う」だけなら、追加費用の意味は慎重に見る。一方、次のような医学的理由があれば70万円にも意味が出る。

- 骨造成の有無が変わる
- インプラントの長さや設計が変わる
- この症例で長期的に有利な治療法になる
- 上部構造・部品設計に明確な違いがある

治療内容がほぼ同じショートインプラントなら、35万円差は大きい。骨造成などを含めて方法自体が違うなら、単なるメーカー比較ではない。

### 試験価格であることの意味

35万円は「MegaGenが本質的に半額だから」ではなく、**医院が最近導入し、試験的に使っている価格**とのこと。

- 今決めるなら価格メリットはある（後で上がる前提）
- 一方で、担当の先生の **MegaGen症例経験がまだ少ない可能性**がある
- ただし **慣れた大学の先生が同席**するなら、経験不足リスクはかなり緩和される（誰が術者か・どこまで関与するかは確認）
- 価格の安さだけで選ぶより、**この製品・長さの医学的理由**の確認が本筋

## 5. 暫定結論と次に聞くこと

### 暫定結論

現時点の情報だけでは、

> 「35万円のMegaGenを避けて、70万円の有名メーカーを選ぶべき」とまでは考えない。

先に確認するのは、

> **なぜMegaGenのその製品・その長さなのか** に医学的な合理性があるか。

### 次に確認したい情報

- MegaGenが AnyRidge / AnyOne のどちらか
- MegaGenのインプラント長・直径
- 70万円のメーカー名・製品名
- 70万円の場合のインプラント長・直径
- 35万円・70万円それぞれに含まれるもの
- 骨造成・サイナスリフトの有無
- CTで6.58 mmを測定した場所

## 備考：MegaGen以外の主要メーカーと短い製品

骨高が限られる症例向けに、6 mm前後の製品を持つ大手の例。製品の有無と、今回の症例で使えるかは別問題。適応・推奨は歯科医師の判断による。

| メーカー | 代表的なシステム | 6 mm以下の例 |
|---|---|---|
| Straumann（ストローマン） | Standard / Standard Plus、Bone Level など | **Standard Plus Short：4 mm**。Standard / Standard Plus に **6 mm** もある |
| Nobel Biocare（ノーベルバイオケア） | NobelActive、NobelSpeedy など | **NobelSpeedy Shorty：6 mm / 7 mm**（骨量が少ない部位向けの短尺ライン） |
| Astra Tech / Dentsply Sirona（アストラテック） | Astra Tech Implant System EV | **Astra Tech Implant EV：6 mm**（直径 3.6 / 4.2 / 4.8 / 5.4 mm など） |

要点：

- 6 mm以下は「MegaGenだけの強み」ではない。上記大手にも短尺がある
- Straumannは **4 mm** まで公式に展開している（主に下顎など条件付きの適応が語られることが多く、上顎左7番にそのまま当てはまるとは限らない）
- 70万円案がどのメーカー・何mm・骨造成の有無かで、上記のどれと比較すべきかが決まる
