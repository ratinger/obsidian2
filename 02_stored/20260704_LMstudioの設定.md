# 目的

LM StudioをAIサーバーとして動作させ、

- 自分のPC
- 別のWindows PC
- Androidスマホ
- Tailscale経由（外出先）

からChatGPTのように利用する。

---

# 現在の構成

```text
[別PC / スマホ / Tailscale]
       │                    │
       │ :3000              │ :1234（直接）
       ▼                    ▼
   portproxy            LM Studio
       ↓                REST API
   WSL Docker          (Windows上)
   Open WebUI
       ↓
   LM Studio (1234)
```

### 詳細構成図

```text
                Windows PC
        +--------------------------------+
        | LM Studio                      |
        |  ├─ gemma-4-e4b               |
        |  └─ REST API :1234            |
        |                                |
        | WSL2                           |
        |  └─ Docker                     |
        |      └─ Open WebUI             |
        |          Port :3000            |
        +--------------------------------+
                   │
                   │ localhost:3000
                   ▼
              ブラウザ（正常）
```

## ① Open WebUI

```bash
docker run -d \
  -p 3000:8080 \
  --add-host=host.docker.internal:host-gateway \
  -v open-webui:/app/backend/data \
  --name open-webui \
  --restart unless-stopped \
  ghcr.io/open-webui/open-webui:main
```

# 🌐 外部公開（重要）

## ⑤ portproxy設定

### 追加

```powershell
netsh interface portproxy add v4tov4 listenaddress=0.0.0.0 listenport=3000 connectaddress=172.27.83.82 connectport=3000
```

---

### 一覧確認

```powershell
netsh interface portproxy show v4tov4
```

例：

```text
0.0.0.0  3000   172.27.83.82  3000
```

---

### 削除

```powershell
netsh interface portproxy delete v4tov4 listenport=3000 listenaddress=0.0.0.0
```

---

## ⑥ Windows Firewall設定

```powershell
New-NetFirewallRule -DisplayName "OpenWebUI 3000" `
-Direction Inbound -LocalPort 3000 -Protocol TCP -Action Allow
```

# 🔌 別PCからLM Studio直接アクセス

Open WebUI（:3000）とは別ルート。LM Studioは **Windows上で直接動く** ので portproxy は不要。

## ⑦ サーバーPC側（192.168.124.25）

### LM Studio設定

Developer → REST API で以下を確認：

- REST API：ON（Status: Running）
- Port：1234
- **Serve on Local Network：ON**（localhost 以外にバインド）

### Firewall（1234番）

```powershell
New-NetFirewallRule -DisplayName "LM Studio 1234" `
-Direction Inbound -LocalPort 1234 -Protocol TCP -Action Allow
```

### 待ち受け確認

```powershell
netstat -ano | findstr :1234
```

期待：

```text
0.0.0.0:1234 LISTENING
```

`127.0.0.1:1234` のみの場合は **Serve on Local Network** が OFF か、サーバー再起動が必要。

## ⑧ 別PC（クライアント）側

### ブラウザで疎通確認

```text
http://192.168.124.25:1234/v1/models
```

JSON（モデル一覧）が返れば成功。

### API接続先（OpenAI互換クライアント共通）

| 項目 | 値 |
|------|-----|
| Base URL | `http://192.168.124.25:1234/v1` |
| API Key | `lm-studio`（任意の文字列で可） |

Cursor、Continue、別PCのOpen WebUI、Python `openai` ライブラリなど、OpenAI互換のクライアントで上記を設定する。

### PowerShellで確認（別PCから実行）

```powershell
Invoke-RestMethod http://192.168.124.25:1234/v1/models
```

# 🧠 重要ポイント整理

## Docker
- `-p 3000:8080` はコンテナ内変換

## WSL
- `172.27.x.x` は内部専用IP

- portproxyで外部公開

- Open WebUI：3000番開放

- Serve on Local Network：ON
