# 八千代との電話を録音する

作成日: 2026-08-29  
出典: [ChatGPT共有](https://chatgpt.com/share/6a925eaf-b0f4-83ee-a7ad-72536a78d603)  
対象: 星野栞さん宅の固定電話（シャープ **JD-AT96**）→ PC（mouse **F4-I7I010B-A**）でAI議事録

会議の最初に「文字起こしのために録音します」と一言入れる（[[02_stored/20260825_braveの録音]] と同じ）。

置き場は名古屋のWeb会議と同じ型。**音声と文字起こしは Vault の外。議事録だけ `12_八千代`。**

| 種類 | フォルダ名 | ファイル名 |
| --- | --- | --- |
| 音声 | `C:\Users\ozeki\Videos\電話\YYYYMMDD` | `YYYYMMDD_相手.mp3` |
| 音声（分割） | 同じ | `part0.mp3` / `part1.mp3` / `part2.mp3`（15分単位） |
| 文字起こし | 同じ | `YYYYMMDD_相手_文字起こし.md` |
| 議事録 | `12_八千代` | `YYYYMMDD_相手_議事録.md` |

例: `C:\Users\ozeki\Videos\電話\20260830\20260830_栞さん.mp3` と `20260830_栞さん_文字起こし.md`。議事録は `12_八千代/20260830_栞さん_議事録.md`。議事録から文字起こしへはフルパス（`[[リンク]]` は使わない）。

Audacity は **ファイル → オーディオを書き出し → MP3**（WAV は使わない。Windows は LAME 内蔵）。mkv 用のソフトは足さない。

文字起こしと議事録は `/6_gijiroku`（[[02_stored/20260825_braveの録音]] の3章）。**最初に Web会議か電話かを聞かれる。** 電話を選ぶと、この表の置き場に書く。

## 結論

**録りたいのは自分と栞さんの会話。機器は自分側。PCは常時起動。** 栞さん宅には置かない。留守はJD-AT96の留守番（1件10分）で足りる。

| やりたいこと | いまの答え |
| --- | --- |
| 自分（Pixel）↔ 栞さん | **機器不要。** Phone Link＋OBS（[[02_stored/20260812_PCからスマホの携帯を使う]]） |
| 自分（自宅の固定電話）↔ 栞さん | **ぱそってれⅡ回線型**を自分側のモジュラーと電話機の間。3.5mm→USBオーディオ→Audacity |
| 出られなかった着信の聞き返し | **JD-AT96の留守番／自動録音（10分）で足りる** |

## なぜ TEA-041 はダメか

JD-AT96は **親機コードレス**。受話器もコードレスで、壁の電話機と受話器をつなぐカールコード（RJ22）が無い。

[シャープ JD-AT96「親機コードレス」](https://jp.sharp/phone/products/jdat96/feature/usability/)

ELPA [TEA-041](https://www.amazon.co.jp/dp/B00JJEC60A) と山善 **まも録 YDR-100AT** は、どちらも **有線受話器のコードの途中に挟む** 機器。コードレス親機・子機では録音できない。

mouse F4-I7I010B-A の左側面は **4極ヘッドセット端子が1つ**だけ、という点は仕様どおり。つながっても、TEA-041側がこの電話機に付かない。

## 場面1: 栞さん宅の固定電話にかかってきた電話

ケアマネ・医院・市など、**家の固定電話に着信する通話**。

### いま使える（機器を買わない）

JD-AT96の **自動通話録音**（[シャープ公式](https://jp.sharp/phone/products/jdat96/feature/security/)）

- 受話器を上げる／通話ボタンで自動録音
- 本体メモリーのみ。**最大120分・100件・1件あたり最大10分**
- いっぱいになると古いものから上書き
- **microSD や USB でPCに出せない**

10分を超える通話は途中で切れる。長い相談は「今から録音」との併用で最大約20分、それでも長い面談には足りない。

PCへ持っていく応急手段は、電話機で再生 → スピーカーホンの音を Pixel / PC で録り直す。音質は落ちる。

### PCでAI議事録にするなら（回線割り込み）

**壁のモジュラーと JD-AT96親機の間**に入れる。コードレス子機で出ても録れる。受話器コードに挟むタイプ（TEA-041・まも録・ロジテック）は不可。

```
壁のモジュラー（アナログ／ひかり電話のアナログポート）
   ↓
回線割り込み型の録音機
   ↓
JD-AT96 親機
   ↓
受話子機・子機で通話（コードレスのままでよい）
```

ひかり電話なら、ホームゲートウェイの **アナログ電話ポート** から親機へ出ているかを現地で確認。

#### ST-386 と ぱそってれ（回線型）

警告を相手に流したくないならぱそってれ。PCを常時置かず本体だけで録るならST-386。JD-AT96では **回線型** だけ。受話器型は不可。

| 項目 | ST-386 | ぱそってれⅡ（回線型） |
| --- | --- | --- |
| Amazon | [B0155VNWDA](https://www.amazon.co.jp/dp/B0155VNWDA) | [B006EFF6O0](https://www.amazon.co.jp/dp/B006EFF6O0) |
| メーカー | 太知ホールディングス KOBAN | 高英電子工業 |
| 税込目安（2026-08） | 約6,380円 | 約4,000円 |
| 接続 | 壁のモジュラー ↔ 親機の間 | 同じ（回線側。受話器側は不可） |
| JD-AT96 子機 | 可（取説にコードレスあり） | 可（回線に出ていれば子機も録る） |
| 相手への警告 | 着信冒頭に必ず流れる。録音したままOFF不可 | なし |
| 本体の録音 | 内部60分・1件最大30分・30件 | なし（PCのHDDへ） |
| PCへ出す | 通話中の3.5mm → USBオーディオ／ICレコーダー | 3.5mmをPCへ。USB給電。専用自動録音ソフトあり |
| 人がいないとき | 本体だけで録れる | **PCを起動しておく必要あり** |
| 電源 | ACアダプター必須 | PCのUSB |
| 向き | つなぎ確認・常設の聞き返し | 警告なしでAI議事録（現地にPCがあるとき） |

買わないもの: [ぱそってれ 受話器型 B0086MWI2W](https://www.amazon.co.jp/dp/B0086MWI2W)（JD-AT96にはカールコードが無い）。eoqo 等の安価な輸入タップは説明が自己矛盾し、常設向きではない。

使えない／向かないもの: サンコー通話自動録音BOX2（親機コードレス不可・完売）、現行パナソニック電話機への買い替え（SDフル録音は生産終了。VE-GD78にスロットなし）。

### 録音の分担（OBSは触らない）

**OBSはWeb会議専用のまま。** 名古屋のBrave Talk（[[02_stored/20260825_braveの録音]]）の eMeet 設定を変えない。

固定電話のアナログ（ST-386の3.5mm）は、OBSとは別の録音機で取る。

```
ST-386 音声出力
   ↓ 3.5mm（モノラル）
USBオーディオアダプター（ライン／マイク入力）
   ↓ USB
F4-I7I010B-A
   ↓
Audacity（MP3で書き出し）
   ↓
文字起こし（日付フォルダへ）→ 議事録は `12_八千代`
```

| 何を録るか | 使うもの | 使わない |
| --- | --- | --- |
| Brave Talk・名古屋のWeb会議 | **OBS**（いまのまま） | Audacity |
| 栞さん宅の固定電話（ST-386） | **Audacity** または **LINE-IN付きICレコーダー** | OBS |
| 自分がPixelからかける（Phone Link） | いまどおりOBSでも可（アナログではない） | ST-386 |

**Audacity**（無料）: [公式](https://www.audacityteam.org/)

1. USBアダプターを挿す
2. Audacity上部の録音デバイスで、そのアダプターだけを選ぶ（eMeetや「既定」にしない）
3. 録音開始 → 通話 → 停止 → **ファイル → オーディオを書き出し → MP3**
4. 保存先は `C:\Users\ozeki\Videos\電話\YYYYMMDD`。ファイル名は `YYYYMMDD_相手.mp3`（例: `20260830_栞さん.mp3`）
5. Windowsの既定のマイク／スピーカーは **eMeetのまま**。USBアダプターを既定にすると、OBSが会議でそれを掴む

**ICレコーダー（LINE-IN）**: PCを出さなくてよい。ST-386 → 3.5mm → レコーダーのライン入力。通話の長さはレコーダー側の容量。あとでUSB/SDでPCへ。栞さん宅に置いておく向き。Windowsの「サウンド レコーダー」はマイクだけになりがちなので使わない。

## 場面2: 自分が Pixel から八千代と話す

固定電話側の工事は不要。通話は Pixel、声の入出力と録音は PC。

1. Windows **スマートフォン連携（Phone Link）** で発信／着信
2. **OBS** でデスクトップ音声（相手）＋マイク（自分）を録画（eMeet の設定は変えない）
3. 録った mkv を `C:\Users\ozeki\Videos\電話\YYYYMMDD` へ移す（`ビデオ\Web会議` に置いたままにしない）
4. 必要なら mp3 にして文字起こし。文字起こしは同じ日付フォルダ、議事録は `12_八千代`

手順は [[02_stored/20260812_PCからスマホの携帯を使う]] の「通話録音」。名古屋のWeb会議は [[02_stored/20260825_braveの録音]]。

Pixel本体の通話録音は地域・機種で制限されやすく、期待しない。

## Pixel 8a で2番号（同じ会話の前半）

Pixel 8aはデュアルSIM対応。物理SIM＋eSIMで番号を2つ持てる。発信時に番号を選べる。

八千代用の番号を分ける、という用途なら可能。**固定電話の録音とは別件。** 録音の本命は上の場面1・2。

## 次にやること

1. 自分↔栞さんは、まず **Pixel＋Phone Link＋OBS** で録る（機器追加なし）
2. 自宅固定電話からもかける／受けるなら、自分側に **ぱそってれⅡ回線型**（[Amazon](https://www.amazon.co.jp/dp/B006EFF6O0)）＋USBオーディオアダプター
3. 栞さん宅の工事・ST-386は、この用途では不要
