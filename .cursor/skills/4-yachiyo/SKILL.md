# 4_yachiyo — 海老名⇔八千代（星野栞さん宅）

海老名から**八千代市緑が丘・星野栞さん宅**までの往復計画を Markdown で出力する。

- **目的地**: 星野栞さん宅（八千代緑が丘駅から徒歩約5分）
- **海老名→大手町（往路）**: 小田急**急行（千代田線直通・我孫子行）**。**乗換なし**（例: 土休日 05:56発→06:57着）
- **大手町↔八千代緑が丘**: 東京メトロ東西線（**東葉直通**優先）
- **往路・大手町**: モーニング → 丸善 → **9:40〜10:10** 東西線発
- **復路・大手町**: **大戸屋**で夕食 → **約1.5時間** 滞在
- **復路・海老名**: 小田急**急行（千代田線直通・伊勢原行）**。**乗換なし**（例: 土休日 19:49大手町→20:58着）。夕食1.5hと直通21:00前着は両立しにくいため、Web ダイヤで夕食時間と列車を調整

## フェーズ 1: 質問（必須）

未指定なら次を1回で聞く:

1. **日付**（例: 2026-06-20）
2. **海老名出発時刻**（例: 5:50）
3. **海老名帰宅時刻**（例: 22:30）
4. **前回ファイル** — `*八千代やること.md`（`@` 付き可）

**前回ファイルの自動選択**: 対象日より前の最新 `*八千代やること.md`。

## フェーズ 2: Web ダイヤ確認（必須）

**目安値だけで書かない。** 次を Web で調べ、実時刻で表を作る。

| 参照 | 用途 |
|------|------|
| [小田急 海老名 上り時刻表](https://www.odakyu.jp/station/ebina/timetable/up/) | 05:56 急行・我（我孫子行）など直通列車 |
| [小田急 海老名 下り時刻表](https://www.odakyu.jp/station/ebina/timetable/down/) | 復路 急行・伊（伊勢原行）直通列車 |
| ジョルダン | 区間確認・新宿経由は直通が無い場合のみ |
| Yahoo乗換案内 | 路線全体の所要時間・東西線 |

**平日/土休日**を日付の曜日に合わせる。

### 往路

| 区間 | 調べ方 |
|------|--------|
| 海老名→大手町 | **急行・我孫子行（千代田線直通）**。指定時刻前後の最寄発。乗換なし |
| 大手町 | モーニング・丸善（東西線発まで） |
| 大手町→八千代緑が丘 | 東西線**快速・東葉勝田台行**（9:40〜10:10 発を優先） |
| （徒歩）星野栞さん宅 | 約5分 |

**早朝の例（土休日）**: 05:56 海老名発 急行・我孫子行 → 06:57 大手町着（同一列車）

### 復路（帰宅時刻から逆算）

| 区間 | 調べ方 |
|------|--------|
| （徒歩）星野栞さん宅 | 約5分 |
| 八千代緑が丘→大手町 | 東西線快速・東葉 |
| 大手町 | 大戸屋・夕食 **約1.5時間** |
| 大手町→海老名 | **急行・伊勢原行（千代田線直通）**。指定時刻前後の最寄発。乗換なし |

**復路の例（土休日）**: 19:49 大手町 急行・伊勢原行（綾瀬方面発・千代田線直通）→ **20:58 海老名着**（同一列車）

### 前回ファイルから引き継ぐ

`## ToDoリスト`（旧: `## 優先項目`）をそのままコピー。`del` 行は除外、**優先順位**順。

## フェーズ 3: 出力

`{YYYYMMDD}_八千代やること.md`（構成: 往路 → 復路 → ToDoリスト）

ヘッダにダイヤ出典（小田急公式・ジョルダン等）を1行記載可。

`plan.mjs` は下書き用。出力前に Web ダイヤで上書きする:

```bash
node .cursor/skills/4-yachiyo/scripts/plan.mjs --date YYYY-MM-DD --depart HH:MM --return HH:MM --base "前回.md"
```

## 完了報告

出力パス、前回ベース、往路（海老名発・大手町着・直通列車名）、東西線発、復路（海老名着）、星野栞さん宅滞在目安、大手町夕食1.5h を日本語で報告する。
