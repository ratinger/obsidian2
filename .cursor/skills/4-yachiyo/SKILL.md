# 4_yachiyo — 海老名⇔八千代（星野栞さん宅）

海老名から**八千代市緑が丘・星野栞さん宅**までの往復計画を Markdown で出力する。

- **目的地**: 星野栞さん宅（八千代緑が丘駅から徒歩約5分）
- **海老名→大手町（往路）**: 小田急**急行（千代田線直通・我孫子行）**。**乗換なし**
- **大手町↔八千代緑が丘**: 東京メトロ東西線（**東葉直通**優先）
- **往路・大手町**: モーニング → 丸善 → 東西線**快速**（9:40〜10:10 発を目安）
- **復路・大手町**: **大戸屋**で夕食 → **約1.5時間** 滞在
- **復路・海老名**: 小田急**急行（千代田線直通・伊勢原行）**。**乗換なし**

## フェーズ 1: 質問（必須）

未指定なら次を1回で聞く:

1. **日付**（例: 2026-06-20）
2. **海老名出発時刻**（例: 5:50）
3. **海老名帰宅時刻**（例: 22:30）
4. **前回ファイル** — `*八千代やること.md`（`@` 付き可）

**前回ファイルの自動選択**: 対象日より前の最新 `*八千代やること.md`。

## フェーズ 2: Web ダイヤ確認（必須）

**目安値だけで書かない。** 次を Web で調べ、実時刻で表を作る。

| 参照 | 用途 |

| `04_timetable/` | Vault 内の時刻表（整合確認・更新） |

### ダイヤ種別（最重要）

日付から **平日 / 土曜 / 日曜・祝日** を判定し、ジョルダンでは**該当タブのみ**参照する。

- **「土休日」でまとめない。** 土曜と日曜で便・時刻が違う区間がある
- 出力ヘッダに `6/20は土曜ダイヤ` のように**曜日を明記**する
- 過去のやることファイルや `04_timetable/` の数値をそのまま流用しない（必ずその日の曜日で再確認）

**今回判明した誤り例（再発防止）**:

| 誤り | 正しい（土曜） |
|------|---------------|
| 大手町09:28発→八千代10:14着 | **09:35発→10:14着**（09:28発は土曜に無い） |
| 八千代16:08発→大手町16:54着 | **16:08発→16:47着**（快速39分。16:54は各停相当） |
| 復路を「東葉勝田台行」と記載 | 上りは **中野行** |
| 大手町19:10発→海老名20:18着（土休日と記載） | 土曜は **19:27→20:32**（19:10→20:18は日曜など別ダイヤ） |

## フェーズ 3: 出力

`{YYYYMMDD}_八千代やること.md`（構成: 往路 → 復路 → ToDoリスト）

`plan.mjs` は下書き用。出力前に Web ダイヤで上書きする:

```bash

```
