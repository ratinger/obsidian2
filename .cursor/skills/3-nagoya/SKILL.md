# 3_nagoya — 海老名⇔名古屋（総合リハビリセンター）

海老名から名古屋の**総合リハビリセンター**までの往復計画を Markdown で出力する。

- **新幹線**: こだまのみ（のぞみ・ひかりは使わない）
- **名古屋市内**: 地下鉄。**東山線は混むため使わない**
- **目的地**: 総合リハビリセンター（八事駅付近・徒歩）

## 主な登場人物

名古屋の登場人物は谷津さん、伸一郎、美奈子さん、和子さん。

## フェーズ 1: 質問（必須）

ユーザーがまだ指定していない場合、**計画作成前に**次を1回で聞く:

1. **日付**（例: 2026-06-13）
2. **出発時間** — 海老名を出る時刻（例: 5:41）
3. **帰宅時間** — 海老名に着く目標時刻（例: 22:30）
4. **前回ファイル** — ベースにする `*名古屋やること.md`（例: `202605 名古屋やること.md`）。`@` 付きパスでも可

同じメッセージに 1〜3 がすべて含まれている場合は省略してフェーズ 2 へ。前回ファイルもメッセージや `@` 参照に含まれていればそれを使う。

**前回ファイルの自動選択**（未指定時）: Vault ルートの `*名古屋やること.md` のうち、対象日より前で最も新しいファイル。なければ `202605 名古屋やること.md`。

## フェーズ 2: ルートと ToDo

### 前回ファイルから引き継ぐ

前回の Markdown から **`## ToDoリスト`**（旧: `## 優先項目`）セクションを**そのまま**コピーする。

- やること・備考は前回ベース
- **フラグ列**: 前回の値をそのまま（`Pass` または空）
- `結果` 列は空でよい（当日記入用）
- 優先順位は前回の値を維持（未入力なら空のまま）

### 新規に作る（時刻表）

往路・復路の表は前回ファイルは参照せず、こだまと地下鉄から**新規計算**する。表形式・（徒歩）表記・往路/復路の区切りは現行テンプレートに従う。

### 時刻表ファイルの事前更新（必須・計画作成の最初のステップ）

**計画を作る前に**、使用する**全路線**の時刻表ファイルを Web（ジョルダン・各社公式）で最新化する。対象は次の5ファイルすべて:

| 使用路線 | 時刻表ファイル |
|---------|---------------|
| 相鉄（海老名⇔新横浜） | `04_timetable/相鉄時刻表.md` |
| 東海道新幹線（こだま） | `04_timetable/東海道新幹線時刻表.md` |
| 桜通線（名古屋⇔御器所） | `04_timetable/名古屋市の桜通線.md` |
| 鶴舞線（御器所⇔八事） | `04_timetable/鶴舞線.md` |
| 名城線（八事⇔総合リハビリセンター） | `04_timetable/名城線.md` |

- 取得日と**ダイヤ改正日**（例: 相鉄 2026-03-14 改正）を各ファイルに記録する
- 古い時刻表ファイルを更新せずに参照して計画を作ってはいけない
- 時刻表ファイルはあくまで下書き。計画で使う便は**当日のダイヤ種別のタブ**で最終確認する

### ダイヤ種別（最重要）

日付から **平日 / 土曜 / 日曜・祝日** を判定し、各社時刻表・ジョルダンでは**該当タブのみ**参照する。

- **「土休日」でまとめない。** 土曜と日曜で便が違う
- 出力ヘッダに `6/14は日曜ダイヤ` のように**曜日を明記**する
- 過去のやることファイルや `04_timetable/` の数値をそのまま流用しない（必ずその日の曜日で再確認）

**実際に起きた失敗（2026-07-11・再発防止）**: 海老名5:54発（相鉄直通）は**日祝ダイヤのみ**の便だったが、日祝の時刻を土曜の計画に書いてしまい、駅で乗る電車が無かった。土曜早朝は5:14の次が6:11。**早朝・深夜は本数が少なく、1本の誤りが致命的**。逆算で作った「都合のいい時刻」をそのまま書かず、必ずその曜日のタブで実在確認すること。

| 確認対象 | 注意 |
|---------|------|
| こだま | JR東海時刻表で**その曜日**の号数・発着 |
| 相鉄（新横浜⇔海老名） | 直通列車の**曜日別**ダイヤ |
| 桜通線・鶴舞線・名城線 | ジョルダンで**発時刻がその曜日の表に存在**すること |

### 出力前チェックリスト

- [ ] **`04_timetable/` の時刻表ファイルを Web で最新化した**（取得日・ダイヤ改正日を記録）
- [ ] こだま・相鉄・地下鉄それぞれ**その曜日のダイヤ**で発着を確認した
- [ ] ジョルダンで選んだ**発時刻が実在**する（別曜日の便を流用していない）
- [ ] **早朝・深夜の便は特に**、その曜日のタブでソース付きで実在確認し、**1本前・1本後の便も注意事項欄に併記**した
- [ ] 地下鉄の**行先表記が乗車方向と一致**（上り/下り）
- [ ] 快速・各停・所要時間を取り違えていない
- [ ] 復路は帰宅時刻から逆算し、名古屋駅に**約1時間10分**の余裕がある
- [ ] 新横浜⇒海老名は**相鉄直通・乗換なし**

### 長距離（こだま）

| 区間 | 目安 |
|------|------|
| 海老名⇒大和⇒新横浜 | 出発から約 35 分 |
| 新横浜→名古屋（こだま） | 約 2 時間 18 分 |
| 名古屋→新横浜（こだま） | 約 2 時間 18 分 |
| 新横浜⇒海老名 | 約 35〜40 分 |

復路のこだまは**帰宅時刻から逆算**して選ぶ。名古屋駅では新幹線発車まで**約1時間10分の余裕**を確保する。

**新横浜⇒海老名**は**相鉄直通・乗り換えなし**（参考: 22:22発→22:58着）。こだま着後の直通列車に合わせる。

### 名古屋市内（地下鉄・東山線回避）

**使わない**: 東山線（混雑のため）

**御器所ルート**（路線図準拠・**既定**）— 東山線は使わない:

| 方向 | 区間 | 路線 |
|------|------|------|
| 往路 | 名古屋 → 御器所 | **桜通線** |
| 往路 | 御器所（乗換） | 桜通線ホーム → **鶴舞線**ホーム（同一駅・約5分） |
| 往路 | 御器所 → 八事 | **鶴舞線**（御器所・川名・いりなか・八事。**名城線ではない**） |
| 往路 | 八事（乗換） | 鶴舞線ホーム → **名城線**ホーム（同一駅・約5分） |
| 往路 | 八事 → 総合リハビリセンター | **名城線**（1駅） |
| 往路 | 駅 → 施設 | 徒歩約3分 |

復路は上記を逆順。**御器所-八事に名城線を使わない**こと（名城線は八事以北で総合リハビリ方面へ向かう）。

### 所要時間の目安（Web調査・余裕込み）

| 区間 | 目安 |
|------|------|
| 名古屋駅 新幹線↔地下鉄 | 徒歩・乗換 **約10分** |
| 桜通 名古屋→御器所 | **約15分** |
| 御器所 桜通↔鶴舞乗換 | **約5分** |
| 鶴舞 御器所→八事 | **約5分** |
| 八事 鶴舞↔名城乗換 | **約5分** |
| 名城 八事→総合リハビリセンター駅 | **約2分** |
| 総合リハビリセンター駅→施設 | 徒歩 **約3分** |
| 新横浜 新幹線↔相鉄 | **約10分** |
| 新横浜⇒海老名（相鉄直通） | **約36分** |

**1分移動は使わない。** 八事駅から施設へ徒歩のみだと約9分かかるため、**名城線で総合リハビリセンター駅まで乗り、徒歩3分**とする。

## 実行方法

```bash
node .cursor/skills/3-nagoya/scripts/plan.mjs --date YYYY-MM-DD --depart HH:MM --return HH:MM --base "202605 名古屋やること.md"
```

- `--base` / `--previous`: 前回の `*名古屋やること.md`。省略時は自動選択
- こだまの号数・発着が分かれば `--out-train` `--out-depart` `--out-arrive` `--back-train` `--back-depart` `--back-arrive` を付ける
