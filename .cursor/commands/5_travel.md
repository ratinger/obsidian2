## 開始時

ユーザーがまだ旅行の概要を書いていない場合は、**作成の前に**次を1回だけ聞いてください:

1. **日程**（例: 2026-08-11〜13）
2. **エリア／拠点**（例: 大塚・池袋、ホテル名）
3. **欲しい成果物**（既定: 行程メモ＋見取り図 `_map.html`＋主要ポイントの Googleマップリンク）
4. **予約情報**（ホテル・特急など。PDF／メモがあれば `@` で渡す）
5. **重点スポット**（本屋・家電・金券・食事など。省略時はエリアから推定）

同じメッセージに十分情報が含まれている場合は、確認を省略して作成を開始してください。

## 実行

1. `.cursor/skills/5-travel/SKILL.md` の手順・出力ルールに従う
2. Web で営業時間・住所・座標を確認する（推測だけでピンを置かない）
3. 行程フォルダ `14_旅行/YYYYMMDD_<エリア略称>/` を作り、行程メモ `YYYYMMDD_<エリア略称>.md` をその下に保存する
4. 同じフォルダにエリアごとの `YYYYMMDD_<エリア>見取り図_map.html` を置く（見取り図は `_map.html` のみ）
5. 主要ポイントの Googleマップリンクは**行程メモ本体**に記載する
6. チャットには作成ファイルと要点だけを返す
