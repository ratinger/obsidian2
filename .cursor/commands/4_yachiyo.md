## フェーズ 1（質問）

未指定なら次を1回だけ聞く:

1. **日付**（例: 2026-06-20）
2. **海老名出発時刻**（例: 5:50）
3. **海老名帰宅時刻**（例: 22:30）
4. **前回ファイル** — 省略時は Vault 内の直近 `*八千代やること.md`

## フェーズ 2（計画作成）

1. **曜日を確定** — 日付から **平日 / 土曜 / 日曜・祝日** を判定。ヘッダに `6/20は土曜ダイヤ` のように明記
2. **前回ファイル** — `## ToDoリスト` を引き継ぐ（`del` 除外、優先順位順）
3. **Web でダイヤ確認**（下記「検証チェックリスト」必須）
4. `{YYYYMMDD}_八千代やること.md` を Vault ルートに出力（往路 → 復路 → ToDoリスト）
5. 可能なら `04_timetable/` の該当ファイルも整合するよう更新
