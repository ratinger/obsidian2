## 前提

- **目的地**: 総合リハビリセンター（八事駅付近）
- **新幹線**: こだまのみ
- **名古屋市内**: 地下鉄。**東山線は使わない**（混雑のため）
- **市内ルート（既定）**: 桜通線（名古屋→御器所）→ 鶴舞線（御器所→八事）→ 名城線（八事→総合リハビリセンター）。**御器所-八事は名城線ではない**
- **前回ファイル**: 指定日の ToDo は**前回の** `*名古屋やること.md` をベースにする（時刻表は新規計算）

## フェーズ 1（質問）

未指定なら次を1回だけ聞く:

1. **日付**（例: 2026-06-13）
2. **海老名出発時刻**（例: 5:41）
3. **海老名帰宅時刻**（例: 22:30）
4. **前回ファイル**（例: `@202605 名古屋やること.md`）— 省略時は Vault 内の直近の `*名古屋やること.md` を自動選択

## フェーズ 2（計画作成）

1. **前回ファイルを読む** — `## ToDoリスト` をそのまま引き継ぐ。`結果` 列は空のままでよい
2. **往路・復路の時刻表** — こだまダイヤを調べ新規作成。名古屋駅に**約1時間10分**の余裕
3. 新横浜⇒海老名は**相鉄直通・乗り換えなし**（参考: 22:22-22:58）
4. `{YYYYMMDD}_名古屋やること.md` を Vault ルートに出力（構成: 往路 → 復路 → ToDoリスト）

```bash
node .cursor/skills/3-nagoya/scripts/plan.mjs --date YYYY-MM-DD --depart HH:MM --return HH:MM --base "前回ファイル.md"
```

`--base` 省略時は対象日より前の最新 `*名古屋やること.md` を使う。
