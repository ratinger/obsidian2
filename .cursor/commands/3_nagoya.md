**3-nagoya** スキルに従ってください。

## 前提

- **目的地**: 総合リハビリセンター（八事駅付近）
- **新幹線**: こだまのみ
- **名古屋市内**: 地下鉄。**東山線は使わない**（混雑のため）
- **市内ルート（既定）**: 桜通線（名古屋→御器所）→ 鶴舞線（御器所→八事）→ 名城線（八事→総合リハビリセンター）。**御器所-八事は名城線ではない**
- **前回ファイル**: ToDo は**前回の** `*名古屋やること.md` をベース（時刻表は新規計算）

## フェーズ 1（質問）

未指定なら次を1回だけ聞く:

1. **日付**（例: 2026-06-13）
2. **海老名出発時刻**（例: 5:41）
3. **海老名帰宅時刻**（例: 22:30）
4. **前回ファイル** — 省略時は Vault 内の直近 `*名古屋やること.md`

## フェーズ 2（計画作成）

1. **曜日を確定** — 日付から **平日 / 土曜 / 日曜・祝日** を判定。ヘッダに明記
2. **前回ファイル** — `## ToDoリスト` を引き継ぐ（`結果` 列は空でよい）
3. **Web でダイヤ確認**（こだま・相鉄・名古屋地下鉄）。下記チェックリスト必須
4. 名古屋駅に**約1時間10分**の余裕。新横浜⇒海老名は**相鉄直通・乗換なし**
5. `{YYYYMMDD}_名古屋やること.md` を Vault ルートに出力（往路 → 復路 → ToDoリスト）
6. 可能なら `04_timetable/` の該当ファイルも整合するよう更新

### 検証チェックリスト（出力前に必ず）

- [ ] こだま・相鉄・地下鉄それぞれ **その曜日のダイヤ** で発着を確認（土休日まとめにしない）
- [ ] ジョルダン等で選んだ**発時刻が、その曜日の表に実在**する
- [ ] 地下鉄の**行先表記が乗車方向と一致**（上り/下りを取り違えない）
- [ ] 乗換区間（御器所・八事）に徒歩5分の余裕を表に反映
- [ ] 復路は帰宅時刻から**逆算**し、名古屋駅余裕1h10mを確保

```bash
node .cursor/skills/3-nagoya/scripts/plan.mjs --date YYYY-MM-DD --depart HH:MM --return HH:MM --base "前回ファイル.md"
```

`--base` 省略時は対象日より前の最新 `*名古屋やること.md` を使う。

出力パス、**判定した曜日とダイヤ種別**、前回ベース、こだま、市内ルート（東山線不使用）、使用列車の発着、滞在目安、チェックリスト実施の有無を日本語で報告する。
