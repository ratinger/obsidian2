# 3 高齢化で出てくる問題の対処（すぐやることとなった場合にやること）

一人あたりの状態(4段階)。**「弱る」は身体だけの話ではなく、体力の低下と認知能力の衰えが同時に進む**ものとして扱う（フレイルで外出・会話・役割が減ると脳への刺激が落ち、MCI（軽度認知障害）→認知症へ進みやすい。別々には来ない）:

| 記号 | 状態 |
| --- | --- |
| A | **元気** … 自立・通常生活 |
| B | **介護されないが弱る** … 体力・余力の低下と**認知能力の衰え（もの忘れ・判断力低下・MCI）が同時に進行**。まだ介護体制なし。本人も配偶者も「歳のせい」と誤認して受診が遅れやすく、**認知症の早期発見・口座凍結前の準備ができるラストチャンス** |
| C | **介護が必要** … 常時または定期の介護・見守りが要る。要介護原因の上位は認知症そのもので、骨折・入院をきっかけに一気に認知機能が落ちることも多い。**介護する側も**ストレス・睡眠不足・孤立で心身と認知を消耗する |
| D | **死亡** |

二人（夫・妻）の組み合わせは、**区別するなら 4×4＝16通り**、**順不同で同じパターンをまとめるなら 4×5÷2＝10通り**（`4*3/2` だと6通りになり、死亡・両方弱るなどが漏れる）。

### 認知能力の衰えへの事前対処（お金と権限の凍結対策）

体と一緒に認知能力も衰える以上、**判断力があるうち（A〜B初期）にしか打てない手**がある。

- 認知症と診断されると **銀行口座・不動産・契約が事実上凍結** される。B段階以前に、任意後見・家族信託・代理人カード・重要情報の共有（印籠）を済ませておくこと。
- かかりつけ医に認知機能の相談ルートを作っておく（もの忘れ外来・地域包括支援センターの連絡先を第2章の「すぐやること」に含める）。
- 判断力があるうちに「どこまで在宅・いつ施設か」を夫婦で文書化しておく。発症後では本人の意思確認ができない。
- 閉じこもり・社会的孤立・難聴の放置・うつは認知症の主要な危険因子。第2章の予防はここに直結する。
