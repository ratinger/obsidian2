## 第2章 趣旨

- **自分史上最大**のテーマとして、前もって方針を決めておく。
- 終了時期は不明だが、**目に見えるものの管理を「大政奉還」する時期**は決めておける。
- **大方針**と**ケース別の想定（A・B・C）**を決め、いざというときに考えられなくなる前に、指針として残す。
- 病気のときは判断力が落ちるのと同様、**その時になってからでは考えられない**。だから今、指針を作る。
- 方針を立てるとき・見直すときは、**道徳を意識する**。配偶者・キーパーソン・介護・医療との関係で、誠実さ・公平・負担の押しつけになっていないか・透明性などを、都度立ち返る。

## 第4章 運用 — チェックすること・お願いすること

### 頻度ごと（毎日・季節・年1回・4年ごと）にやること

- **チェックする（自分自身・お互い・必要なら外部）**  
  - 特に**認知症のサイン**：忘れ物が多い、時間がわからない、幻覚、怒りやすい、計画が立てられない、身だしなみ・歯・食事・体力づくりがおろそかになる、集中力の低下、転ぶ。  
  → 気になる変化が出たら、早めに受診・相談。
  - **認知症ドック** … まだ検討中だが、受けるかどうかを決める（早期の目安づくり・経過観察のため）。
  - **受診判断の原則** … 「認知症かどうか」「認知症の専門医を受診すべきか」は、本人だけの判断に委ねない。家族・キーパーソンが伴走して判断する。
- **「印籠」を渡す** … 施設や病院に行くことを、信頼できる人に委ねられるよう、事前に書面で示す。
- **財産を示す** … おおよその額と、アクセス方法（誰がどこまで見るか）を、キーパーソンに伝える。
- **大政奉還する** … 身体と財産の管理を、いつから誰に渡すかを決め、実行する。
- **ACP（人生会議）を示す** … 医療・介護の希望を、本人の意思として残す。
- **GPS・見守りカメラ・自動で鍵を開ける* … 安全と見守りのため、必要に応じて導入する。
- **死後のお願い事項を示す** … 葬儀・納骨・遺品・連絡先などを、文書で残す。
- 自分ができなくなったことを記録し、代替手段を考える

## 第5章 非常事態への対応

日ごろの運用（第4章）とは別に、**倒れた・急病・入院・認知症の急な悪化**など、いざというときの初動と判断を決めておく。

### 想定する非常事態

| 事態 | 初動の例 |
| ------ | ------ |
| **転倒・転落** | 動かさず状態を確認。頭打ち・出血・動けない → 119。軽くても後から悪化することがあるので、本人・家族が不安なら受診。 |
| **急病・意識がおかしい** | 119。同時にキーパーソンに連絡。持病・服用薬・かかりつけ医を伝えられるよう、お薬手帳・メモを手渡せる場所に。 |
| **入院が必要と言われた** | 印籠（施設・病院に行くことを委ねる書面）や ACP（人生会議）を、病院・ケアマネに示す。キーパーソンが同行・連絡役になることを事前に決めておく。 |
| **認知症の急な悪化**（徘徊・暴言・自傷の恐れ・昼夜逆転で介護が崩れる） | かかりつけ医・地域包括・キーパーソンに相談。入院・施設入所の判断が必要な場合は、印籠に沿ってキーパーソンが判断。 |

### 事前に用意しておくもの

- **緊急連絡先一覧** … 家族・キーパーソン・かかりつけ医・地域包括。電話のそば・冷蔵庫など、すぐ見える場所に。
- **印籠** … 「施設や病院に行くことを、〇〇に委ねる」旨の書面。非常時に病院・施設に提示できるよう、写しをキーパーソンが持つ。
- **ACP（人生会議）** … 医療・介護の希望。救急・入院時に医師に見せる。
- **お薬手帳・服用メモ** … 救急搬送時に持っていく。誰が持って病院に届けるか決めておく。

### 役割の確認

- **119をかける人** … 同居の配偶者、または見守りで駆けつけたキーパーソン。本人が自分でかけられない場合に備え、日頃から「誰が最初に動くか」を話し合っておく。
- **病院・施設とのやりとり** … 本人の判断が難しいときは、印籠に書いた人（キーパーソン）が窓口になる。付き添い・代行サービス（第9章参照）の利用も選択肢。

## 第7章 参照：前提となる知識（脳と身体の衰え）

- **脳が衰えると判断ができなくなる**。直感は残っても、信頼性は低い。
- **認知症関連の受診判断は、本人だけでは難しいことがある**。  
  ⇒ 「認知症かどうか」「認知症の医者に行くべきか否か」は、家族・キーパーソンが確認し、必要なら受診につなげる。
- **認知症で一番怖いのは、物忘れそのものではなく社会性の低下**。  
  ⇒ 自分をケアできない／他人をケアできない状態が進むと、生活全体の安全と関係性が崩れやすい。
- **身体が衰えれば脳も同様に衰える**。脳だけが健全なまま、ということはほぼありえない。
- **具合が悪いとき**は、身体も動かず、脳の働きも落ちる。  
  ⇒ 怒っていることなども、自覚できないことがある。

→ だからこそ、**判断力があるうちに指針と仕組みを作っておく**。

## 第10章 資産とお金の方針（案）

### 1. 資産の目的

- この資産は、主に次の目的で使う。  
  - 老後の生活費（住まい・食費・移動など）  
  - 介護・医療費  
  - 妻の生活の安心のための予備費  
  - 余らせすぎないための「楽しみ枠・前倒しで使う枠」

一番の懸念は一人が要介護になること。

### 2. 「減らしてよい額」と「減らしてはいけない額」

- 安全資産（原則として減らさない土台）は、**生活を維持するための最低限のライン**とする。  
- それを超える部分は、**意識して使ってよい余裕分**とみなし、生活の質向上・楽しみ・前渡し（贈与・寄付など）の候補とする。

### 3. 使う優先順位

- お金を使う優先順位は、次の通りとする。  
  1. 健康と介護（治療・リハビリ・介護サービス・移動手段）  
  2. 生活の質（住環境・安全対策・家事支援など）  
  3. 趣味・楽しみ（旅行・外食・学びなど）  
  4. 相続・贈与・寄付（余裕がある場合に検討）

### 4. 余らせすぎないための考え方

- 「資産が枯渇するのも怖いし、かといって大きく余らせて終わるのも怖い」という気持ちを前提にする。  
- 一定の年齢以降は、**元気なうちに使う・頼む・贈る**ことを意識し、「後悔しない使い方」を優先する。  
- 余裕分については、毎年・数年ごとに、妻との話し合いで「今年はどこまで使うか／前渡しするか」を決める。

### 5. 判断力が落ちたときの資産管理

- 判断力が落ちたときは、次の方針に従う。  
  - 大きな契約・解約・出金は、一人で決めず、キーパーソン（家族など）と相談してから行う。  
  - 必要に応じて、**家族信託や管理機能付きの信託商品**を検討し、「使えないまま凍結するリスク」を減らす。  
  - 自分が決められなくなった場合は、第6章の大方針と本章の内容をもとに、キーパーソンに判断を委ねる。

## 第11章 一人暮らしになったときの準備と運用（案）

### 1. 想定するパターン

- 自分が先に亡くなり、**妻が一人暮らしになる場合**。  
- 妻が先に亡くなり、**自分が一人暮らしになる場合**。

どちらの場合も、「急に始まる一人暮らし」ではなく、**前もって準備しながら移行していく**ことを前提とする。

### 2. 住まいの方針

- 一人暮らしになったとき、次の観点で住まいを見直す。  
  - 段差・階段・浴室など、安全に暮らせるか。  
  - 買い物・通院・介護サービスへのアクセスが良いか。  
- 必要であれば、**バリアフリーへの改修**や**住み替え（小さな部屋・サービス付き住宅など）**も選択肢とする。

### 3. 家事・買い物・通院の支援

- 一人では難しくなる作業について、早い段階から「外部サービスを使う前提」で考える。  
  - 掃除・洗濯・ゴミ出し・買い物代行。  
  - 通院付き添い・タクシー・見守りサービス。  
- 第9章のツール・サービス一覧を参照し、**優先して導入したいサービス**に目星をつけておく。

### 4. 見守りと連絡の仕組み

- 一人暮らしになったときの「連絡の基本形」を決めておく。  
  - 日常の連絡頻度（例：週に〇回、誰に連絡するか）。  
  - 連絡が途絶えたときに動いてもらう人（キーパーソン・近所の人など）。  
- 必要に応じて、**見守りカメラ・センサー・GPS**などを導入し、「倒れても発見される」状態を作る。

### 5. お金の出し方と頼み方

- 一人暮らしでも、**自分一人で抱え込まない**ことを原則とする。  
  - 一定額以上の支出や契約は、事前にキーパーソンと相談する。  
  - 生活費の引き落としや固定費の支払いは、できるだけ自動化しておく。  
- どうしても難しいときは、**第10章の資産方針と第6章の大方針に従い、キーパーソンに任せる**。
