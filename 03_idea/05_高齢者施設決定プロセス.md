## 第7章 ステップ4：施設の種類を絞る

**目的**: 要介護2・記憶弱化に合う**住まいの型**を決める。

| 種類 | 概要 | 和子さん向けの目安 |
| --- | --- | --- |
| **家族と同居** | 親族宅で共同生活＋訪問介護・デイ等 | **本人第一希望**だが **家族判断で不可**（一人で一人を見るのは無理。**姉同居も反対**） |
| **有料老人ホーム** | 民間。介護付き〜健康型まで幅広い | **本人第二希望＝家族の本命**。空床あり・判断早い場合に有力。月額・一時金要確認 |
| **サービス付き高齢者向け住宅（サ高住）** | 安否確認＋オプション介護 | 要介護2単独では**不足になりやすい**—介護付きか要確認 |
| **グループホーム** | 認知症対象の小規模 | 記憶弱化が進行・認知症診断なら**候補** |
| **介護老人保健施設（老健）** | 医療・リハビリ中心（入所は一時的） | **入院→老健→有料等** の**中継**として使う |
| **単独在宅＋ヘルパー** | 今の延長 | **「一人暮らし無理」判断後は原則除外** |

※ **特養**は原則 **要介護3以上**のため、現状（要介護2）では **候補から除外**。

**この段階の決め方**

1. **姉と合意** … 家族同居は **見送り**（理由：一人で一人を見る介護は無理）  
2. ケアマネの提案を聞く → **施設**（有料・グループホーム等）に絞る  
3. **有料（介護付き）** を中心に調査  
4. 記憶の程度次第で **グループホーム** をリストに入れる  

**アウトプット**: 「第1候補の施設タイプ」（例：有料希望、並行してグループホームも見学）。

- 95歳・記憶弱化 → **無理に即決させない**。「今日見た中で気になったところ」を聞く  
- 拒否が強い場合 → 短時間の見学、または家族＋ケアマネで先に1件見学  

**見学の分担**

| パターン | 誰 | いつ |
| --- | --- | --- |
| **A. 姉単独下見** | 姉（日程は伸一郎がケアマネと調整） | **いつでも**（車40分） |
| **B. 姉＋自分** | 両者 | 名古屋訪問日（`11_名古屋/*`） |
| **C. 本人同席** | 姉＋本人（＋自分がいれば） | 和子さんの体調・拒否度に合わせ **短時間** |

- **姉単独下見** のあと → **その日のうちに** 自分へ共有（良い点・気になった点・写真）
- 見学予約は **ケアマネ経由** がスムーズ（**ケアマネとのコンタクトは伸一郎**）

※ **注**: 見学は **紹介業者と回る** ことも検討する（担当者が使えるかは一緒にまわらないとわからない）。在宅の空白補強としては **[イチロウ](https://ichirou.co.jp/) などの保険外有料サービス** も検討する（優先1-6）。

**アウトプット**: 見学メモ（各施設・Pros／Cons・本人の一言）。**姉版／自分版** を1つにまとめる。

## 第10章 ステップ7：第1希望を決める

**目的**: 申込みに進む施設を **自分＋姉＋ケアマネ** で確定。

| 決めること | 内容 |
| --- | --- |
| **住まいの型** | **施設**（家族判断の **本命**）。本人第一希望の家族同居は **見送り済** |
| **第1希望** | 申込先（施設） |
| **第2・第3希望** | 待ち・見送り時用 |
| **入居時期** | 即日／○月／空床待ち |
| **在宅つなぎ** | 入居まで **現行の週間スケジュール**（デイ・ヘルパー・家政婦・姉日曜）を維持。不足分はヘルパー増・短期入所 |
| **自宅** | 入居後の扱い（空家・売却・賃貸は**別途**検討） |

**本人との合意**

- 希望順位 … **①家族 ②施設**（本人）／ 家族は **同居不可** → **施設で進める**  
- 説明の軸 … **一人で一人を見るのは家族でも無理**（自分・姉とも）。**施設なら見守り・介護・足のケアが続く**。面会・Web・電話で **家族のそばにいる**  
- 完全な納得は難しい場合もある → **安全側に決め、入居後の様子で調整**  
- 印籠・事前の話し合いがあれば参照（`03_idea/01_撤退戦2025`）

**姉との決定**

- 第1〜3希望・入居時期・費用感は **電話 or 対面で両者OK** してから申込

**意見が割れたときの決め方（事前合意）**

1. **安全を最優先** … 見守り・夜間対応・足の傷ケアが手厚い方を取る。費用安・本人の好みだけでは覆さない  
2. **現地の現実を重く見る** … 姉の面会しやすさ・急変時の駆けつけ可否は、海老名からの印象より優先する  
3. **決めきれないときは短い期限で試す** … 第1希望で申し込み／つなぎ入居し、**1ヶ月で再評価**（合わなければ転居も可、と最初から言っておく）

**アウトプット**: 決定メモ（第1〜3希望・入居目標時期）。**姉にも送った日付** を記録。

## 第11章 ステップ8：申込・空床待ち

**目的**: 正式な入居手続きを進める。

**一般的な流れ**

1. 入居申込書提出  
2. 施設側の選考・面談（本人・家族）  
3. かかりつけ医の**意見書**  
4. 空床連絡 → 入居日調整  
5. **待機リスト**— 空床待ちがある場合は期間を確認。並行して別候補の**つなぎ**を検討  

**待機中の在宅**

- **現行スケジュールを維持**（第1章 1-3）  
  - 月・木・土 … **デイサービス**  
  - 火・金 … **ヘルパー**（**火・土** … 自分 **Web会議**）  
  - 水 … **家政婦**（食事）  
  - 日 … **姉が訪問**  
  - **金曜** … **訪問診療**（月2回）＋自分 **Web同席**（入居まで継続）  
- **それでも足りない時間帯**（主に **夜間**）… ケアマネに **ヘルパー増・夜間見守り・短期入所** を相談  
- **一人暮らし単独は避ける**方向（サービス外・夜間は特に）  
- **かわな病院（金曜・月2回・訪問診療）・訪問看護（足の傷）** … **入居まで継続**。診療日は自分 **Web同席**（ヘルパー日と同日）。傷の変化は共有  
- **カメラ・センサー** … 待機中も継続。**異常検知時は姉へ連絡**（遠隔だけでは対応しきれない前提）  
- 足の傷の **感染・悪化** → かわな病院／訪問看護／119 の連絡順を **姉と事前に決める**  
- 急変（転倒・迷走）→ **老健経由** も選択肢  

**アウトプット**: 申込控え・待機番号（あれば）・入居予定時期の目安。
