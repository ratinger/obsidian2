# nest-cast 使い方（ラズパイ）

Google Nest へ MP3 を Cast 再生する。定時は cron + CSV で管理。

**場所:** `/home/pi/nest-cast/`  
**詳細仕様:** Obsidian `03_idea/06_Google nestをラズパイで鳴らす.md`

---

## いちばんよく使う操作

### 定時再生を止める

```bash
nano ~/nest-cast/config.txt
```

`enabled=0` にして保存。時刻（`time_schedule.csv`）はそのまま。

### 定時再生を再開する

```bash
nano ~/nest-cast/config.txt
```

`enabled=1` にして保存。

### 定時の時刻を変える

```bash
nano ~/nest-cast/time_schedule.csv
```

1 行 1 時刻（24 時間表記）。例:

```
7:00
12:00
13:00
17:00
```

`#` で始まる行はコメント（無視される）。

### 今すぐ 1 回だけ鳴らす（手動）

```bash
~/nest-cast/run_scheduled.sh
```

3 台（**全体** グループ）からチャイムが鳴る。

### ログを見る

```bash
tail ~/nest-cast/schedule.log
```

## ファイル一覧

| ファイル | 編集する？ | 内容 |
| --- | --- | --- |
| **`config.txt`** | **よく** | 定時 ON/OFF |
| **`time_schedule.csv`** | **よく** | 毎日鳴らす時刻 |
| `time_schedule_once.csv` | たまに | 一度きりの時刻（鳴ったら自動削除） |
| `play_mp3.py` | たまに | 再生先・MP3・IP など |
| `check_schedule.py` | 基本いじらない | cron から毎分実行 |
| `run_scheduled.sh` | 基本いじらない | 再生処理（HTTP 起動 → play） |
| `list_devices.py` | いじらない | Nest 一覧確認用 |
| `run_alarm.sh` | いじらない | 手動 1 回用（旧） |
| `media/` | たまに | MP3 ファイル置き場 |
| `schedule.log` | いじらない | 定時の実行ログ |
| `venv/` | いじらない | Python 仮想環境 |

## config.txt（ON/OFF）

```
# 定時再生 ON/OFF（1=ON, 0=OFF）
enabled=1
```

| 値 | 意味 |
| --- | --- |
| `enabled=1` | 定時 **ON** |
| `enabled=0` | 定時 **OFF**（毎日・once とも鳴らない） |

`true` / `false` / `on` / `off` も可。ファイルが無い場合は **ON** 扱い。

---

## time_schedule.csv（毎日の時刻）

```
7:00
12:00
13:00
17:00
```

- 形式: `H:MM` または `HH:MM`（例: `7:00` と `07:00` は同じ）
- 空行・`#` 始まりの行は無視
- **cron が毎分チェック**し、一致した分に 1 回だけ再生

---

## time_schedule_once.csv（一度きり）

試し鳴らし用。例: 18:30 に 1 回だけ

```bash
echo "18:30" >> ~/nest-cast/time_schedule_once.csv
```

- 鳴った時刻の行は **自動で削除** される
- `config.txt` が `enabled=0` でも **鳴らない**（全体 OFF）

---

## play_mp3.py（再生設定）

主な設定（ファイル先頭）:

| 変数 | 現在の値 | 意味 |
| --- | --- | --- |
| `DEVICE_NAME` | `"全体"` | Cast 先（スピーカーグループ） |
| `PI_IP` | `192.168.124.20` | ラズパイの LAN IP |
| `MP3_FILE` | `12_SchoolChime.mp3` | `media/` 内のファイル名 |
| `HTTP_PORT` | `8000` | HTTP サーバーのポート |

**1 台だけ鳴らす**ときは `DEVICE_NAME` を変更:

- `"キッチン"` … Nest Hub
- `"オフィス"`
- `"ベッドルーム"`

Nest 名の確認:

```bash
cd ~/nest-cast && source venv/bin/activate && python3 list_devices.py
```

---

## 裏側の動き

1. **cron**（毎分）→ `check_schedule.py`
2. `config.txt` が ON か確認
3. 現在時刻が CSV と一致 → `run_scheduled.sh`
4. HTTP サーバー未起動なら起動 → `play_mp3.py` → Nest が MP3 を GET して再生

**リブート後:**

- HTTP サーバーは **常時は立たない**（問題なし）
- cron は自動再開
- 定時の直前に `run_scheduled.sh` が HTTP を起動する

## 困ったとき

| 症状 | 確認 |
| --- | --- |
| 定時が鳴らない | `config.txt` が `enabled=1` か、`crontab -l` に check_schedule があるか、`schedule.log` |
| 手動も鳴らない | `list_devices.py` で「全体」が見えるか、Nest の電源・同一 Wi-Fi |
| 1 台だけ鳴る | `DEVICE_NAME` が `"全体"` か（グループ名と完全一致） |
| 無音 | 定時なら `run_scheduled.sh` 経由か（HTTP 自動起動）。手動は `run_scheduled.sh` を使う |

詳細は `03_idea/06_Google nestをラズパイで鳴らす.md` の第 6 章・6-9。
